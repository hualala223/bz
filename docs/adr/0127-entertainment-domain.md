# ADR-0127: 影院域改版「娱乐域」（类型体系/国家/题材/集数/感想导出）

日期：2026-09-22 ｜ 票：issues/291-entertainment-domain.md ｜ 状态：已接受

## 背景

用户要求把影院（cinema）域改为「娱乐」：类型改为 电影/电视剧/短剧/小说，增加「国家」（内地/港台/美剧/韩剧 + 自定义固定）与「类型」（悬疑/爱情/年代等 + 自定义固定）两级分类，电视剧/短剧加「总集数」「正在看集数」，并新增感想导出（单项/多项）。

现状：cinema 域类型体系为 电影/剧集/动漫/纪录片/公开课 五组细分 tag；状态由评分推断（想看 -1 / 在看 0 / 已见 >0）；frontmatter 已有豆瓣抓取的「制片国家/地区」（多值串）与「类型」（题材串），均为纯文本非选项。数据 `我的/影视/*.md` 受兼容性冻结保护。

用户裁决（票 291，两轮 grill 均全盘采纳推荐）：门面改名 + 数据目录迁移（改浅不改深）、旧类型组保留、国家待选项规范化、题材多选、集数半自动、导出落笔记。

## 决策

1. **门面改名「娱乐」，骨架不动**：面板标题、弹窗文案、命令显示名全改「娱乐」；域 id `cinema`、`src/cinema/` 目录、命令 id 前缀 `bz-cinema-*`、设置键 `cinema*`、smartcat 域事件通道 `'movie'` 全部不变（外部裸调用契约与联动方零改动优先于命名洁癖）。
2. **数据目录一次性迁移**：默认值 `我的/影视` → `我的/娱乐`；onload 时旧目录存在且新目录不存在则整目录移动（Obsidian renameFolder 保持链接）；新目录已存在则不迁移并提示。`cinemaFolderPath` 为旧默认值时平移新默认值；`movieDirectory`（日记侧归类键）不动。这是兼容性冻结首次被用户授权打破的数据位置变更，迁移只搬家不改内容。
3. **顶级类型固定七项，不开放自定义**：`电影/电视剧/短剧/小说/动漫/纪录片/公开课`。剧集组退役，细分 tag（国产剧/美剧/英剧/德剧/日剧/韩剧/哥伦比亚剧）归一映射为「电视剧」；电影→电影；动漫细分/纪录片/公开课原样保留为顶级类型（历史数据不塞「其他」）；未知 tag 仍归「其他」。顶级类型牵动集数输入、豆瓣抓取开关等行为逻辑，不开放自定义。
4. **国家字段**：新增 fm 键「国家」，单值单选。默认待选项 **内地/港台/美国/韩国**（用户原话「美剧/韩剧」规范化——剧种名不适配电影与小说，已确认）。编辑窗 chips 单选，行尾「+」自定义，自定义项持久化 data.json `entertainmentCountries` 固定进待选项池（同 collectCategories 先例，全局共享）。豆瓣「制片国家/地区」字段原样保留，不参与选项逻辑（多值合拍片无法干净映射单选）。国家筛选条加「未填」桶（存量条目逐条补填的轻量引导，不做自动预填——歧义填错比空着更糟）。
5. **题材字段**：复用现有 fm 键「类型」，顿号分隔字符串（如「悬疑、爱情」）。多选 chips；默认待选项 悬疑/爱情/年代 起步；自定义项持久化 data.json `entertainmentGenres`。豆瓣抓取写入的题材串按分隔符兼容读取，命中待选项自动勾选。
6. **集数（仅电视剧/短剧）**：新增 fm 键「总集数」「正在看集数」（数字）。表单在 类型∈{电视剧,短剧} 且状态=在看 时显示两个数字输入；「正在看集数」≥「总集数」时 toast 提示可标已看，**不自动改状态**（半自动：防误触不添堵）。在看状态卡片角标显示 `正在看/总集数` 追剧进度。
7. **感想导出**：新命令 `bz-cinema-export`（显示名「娱乐： 导出感想」，命令 72→73）+ 列表工具栏「多选」入口；多选模式勾选 → 生成导出笔记落盘 `我的/娱乐/感想导出/`（文件名含时间戳）。条目卡含 名称/类型/国家/题材/评分/观影日期/感想。UI 文案「影评」统一改「感想」，**fm 键「影评」不动**（零数据迁移）。
8. **豆瓣抓取收窄**：仅 电影/电视剧 自动入抓取队列；短剧/小说跳过（豆瓣影视接口搜不到/不适用），「在豆瓣打开」手动动作保留（豆瓣搜索页书剧通吃）。
9. **分析页最小跟随**：统计维度按类型动态聚合，天然兼容七项体系；集数维度**不**进分析页（值得单开一票）。状态推断语义（评分三态）不变。

## 后果

- 命令数 72→73；`EXPECTED_COMMAND_IDS` 同步 +1；门禁数字以 vitest 输出为准。
- home/recap/checkup/diary 流读影视路径均走 `resolveCinemaFolderPath()` 单点（ADR-0115），默认值一改全域跟随；迁移后旧路径失效由该单点吸收。
- 兼容性冻结条款（AGENTS.md）就 `我的/影视` 目录位置与新 fm 键两项被本 ADR 授权修订：旧 frontmatter 字段全部继续可读，属增量不破坏。
- TYPE_COLORS 需为 电视剧/短剧/小说 配色；「剧集」色值由电视剧继承。
- data.json 新增两键为非敏感配置（选项池），不涉密钥治理（vault data.json 已 gitignore）。
