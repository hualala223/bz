# ADR-0123：日记模板成为日程三段唯一真源（删空 `- [ ] ` 占位、顺延建档同一真源）

## 背景

用户 2026-09-14 报「日程规划的模板现在又不对了」。回溯确认**日程规划代码没被改坏**，是两条建档路径打架：

- 待办顺延（`src/todo/diary-sync.ts`，ADR-0122）在插件启动 `onLayoutReady` 时发现今天日记不存在 → 按「`## 代办事项` + 空行 + 首行」自己建档，**不读模板**；
- 日程规划（`src/diary/daily.ts` `planDiary`）随后发现文件已存在 → 只能走 `appendPlanToDiary`，在文末追加 `# 日程规划` + 三段。

后果（`我的/日记/2026-09-14.md` 实证）：文件里出现**两个 `## 代办事项`**（一个顶格、一个在 `# 日程规划` 下），骨架全缺，写日记因找不到 `# 随笔` 落到文末——用户记下的两条抱怨（模板被改、待办位置不对）同源。

另一处：`## 代办事项` 之下代码恒拼三个 `- [ ] ` 空占位。用户裁定**不要空三行再接内容**，待办行直接写在该小节下，模板里那三个占位删掉。

## 决策

**1. 日程三段搬进模板文件，模板成为唯一真源。**

`# 日程规划` 之下的 `## 代办事项` / `## 完成情况跟踪` / `## 备注` 由 vault 模板 `CONFIG/TEMPLATE/模板-日记.md` 自带：

```md
# 日程规划

## 代办事项

## 完成情况跟踪
| 计划完成 | 实际完成 |
| -------- | -------- |
|  |  |
|  |  |
|  |  |

## 备注
1. 
2. 
3. 
```

- 三个 `- [ ] ` 空占位删除（用户裁定）；`## 完成情况跟踪` 空表与 `## 备注` 的 `1. 2. 3.` 保留不动。
- 新增纯函数 `extractPlanBlock(template)`：从模板 `# 日程规划` 标题之后截取该段（只收首尾空行，行内逐字保留）；模板缺标题时退回 `buildPlanContent()`。
- `buildPlanContent()` 保留为**兜底块**（形态与模板同构，同样不含空占位），只在模板不完整、或给存量旧文件补节时使用。
- `FALLBACK_DIARY_TEMPLATE` 同步补三段，内置兜底与模板同构。
- `buildDiaryFileContent(template, date)` 不再拼接日程块——产物 = 模板原文（frontmatter 规整后）。

**2. 两条建档路径共用同一真源。**

- `readDiaryTemplate(app)` 由 private 改 export；`writeDiarySection` 新增 `seedWhenMissing` 选项（文件缺失时把「建档初稿」交给 transform，而不是给空串）。
- todo 域顺延与「新增待办」建档读同一模板铺骨架，投影行因此**天然落进模板自带的 `## 代办事项`**，不再产出顶格文件。
- 日程规划 `planDiary` 一次读模板、两个分支共用；行为不变（缺失建文件 / 已有双标记提示不重复 / 缺标题补块）。

**3. 修「小节已存在但无新行」被误判为「小节不存在」。**

`rollOverContent` 原来只看 `editSectionLines(...).changed`：小节存在但没有新行可补时 `changed === false`，被当成「小节不存在」再去文末建节（实际会往小节尾插两个空行，天天漂）。改为闭包记录「小节是否命中」，命中即原样返回、文件一字不动。

**4. 存量与本次乱掉的文件。**

- `我的/日记/2026-09-14.md` 手工重排为骨架形态：5 条待办投影落 `# 日程规划` → `## 代办事项`；`**📖 06:45**` + 正文段归位到 `# 随笔`；内容一行不丢。
- `我的/日记/2026-09-13.md` 是当天快照，不动（用户裁定）。

## 后果

- 插件启动建档的文件与手动「日程规划」产物**同形**，不再出现两个 `## 代办事项`。
- 用户改模板（加行、改表头、动备注）即刻对新建文件生效；代码里只剩一份兜底字面量。
- 待办面板「新增条目」在日记缺失时也铺骨架，不再产出只有一行标题的文件。

## 风险与缓解

- 模板文件**不在 git 内**（属 vault），改坏无法回滚 → 改动前已备份到 `.scratch/283-diary-plan-block-template-source/模板-日记.md.bak-20260914`。
- 磁盘上另有 `仓库-新\随笔库\CONFIG\TEMPLATE\模板-日记.md` 与 `仓库-旧-不动\...\符号链接\CONFIG\TEMPLATE\模板-日记.md` 两份旧模板（`##` 层级、内容不同），属别的 vault，本次未动。

## 备选（未采纳）

- **三段留在代码里、只删三行占位**：用户两轮表态都指向「模板说了算」（ADR-0112 原承诺「宏读它、插件也读它」），且以后改骨架还得改代码。
- **顺延保持不铺骨架，改由日程规划先建文件**：日程规划靠用户手动触发，而顺延是插件一启动就发生的路径，仍会抢在前面。
- **给待办投影另起 `## 待办事项` 小节**：模板里已有 `## 代办事项`，共用一小节省一次冻结面改动，语义上也确实都是「当天要办的事」（2026-09-13 的文件已是这种形态）。
