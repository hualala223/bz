# 做题家出题链路单篇化：批量协议退役 + 超时/重试/关思考（ADR-0079）

ticket 176：核查「复习出题」AI 调用链发现——批量出题协议要求模型按笔记路径回显 JSON 键，错键被当成功（静默回退旧题）；AI 请求无超时无重试，挂死/限流直接卡死或丢篇。经排查确认 `quizUpdate`/`updateQuiz`（「更新题库」批量入口，ADR-0045 退役命令的模块直调残留）已无任何调用方——现行唯一出题路径是复习域 `regenerateQuestions` 的**单篇**调用。

## 背景

- 原链路：`ensureQuestions` 无条件先走 `generateBatch`（哪怕只有 1 篇），失败才降级逐篇。批量协议要求模型输出以笔记完整路径为键的 JSON 对象——中文长路径极易被改写；回错键时该篇静默缺失，代码却按成功分支收尾（「已为 0 篇笔记生成题目」），上层 `regenerateQuestions` 静默回退旧题。
- AI 请求层：`aiService.json()` 未传 `signal`（ticket 141 已支持），fetch/requestUrl 均无超时——请求挂死时复习循环永久卡住且不可取消；429/5xx/网络抖动一次即失败，该篇被跳过。
- 提示词：单篇模板开头硬编码「四选一（每题一个正确答案）」与多选开关自相矛盾；内容截断单篇 3000/批量 2000 字符不一致且过长笔记后半段永远不出题。
- 校验不对称：单篇一题坏 throw 整篇作废，批量口径是逐题过滤——兜底路径反而更脆。

## 决策

1. **批量协议整体退役**：删 `quizUpdate`/`updateQuiz`/`generateBatch`/`buildBatchPrompt` 及其降级分支，`ensureQuestions` 逐篇生成 + 每篇即时落盘。ADR-0045 退役的「更新题库」入口至此连模块直调层一并消失；quiz 数据格式（quiz.json `{notes:{path:questions[]}}`）不变。若未来需要多笔记批量入口，应以「分批单篇调用」重建而非恢复键回显协议。
2. **请求超时**：出题请求统一带 `AbortSignal.timeout(90s)`（`AbortSignal.timeout` 不可用的老 WebView 退化为无超时，与旧行为一致）；超时 AbortError 不重试。
3. **瞬时失败退避重试**：generator 层包装（不动 core/ai.ts，避免影响五域）——非 AbortError 且非配置类错误（`/^未配置|^未找到 AI 配置/`）重试至多 2 次，退避 1s/2s；JSON 提取失败属提取层错误不重试。
4. **出题显式关思考**：请求带 `modelOptions.enable_thinking: false`（智谱/方舟由 core 层既有方言翻译为 `thinking:{type:'disabled'}`）——防豆包自适应思考吃掉 max_tokens 截断 JSON，出题亦无需思考。
5. **response_format 400 降级**（唯一 core/ai.ts 改动）：`prompt()` 主路+兜底双双失败且报文提及 `response_format` 时，去掉该字段按主路重试一次；非纯 JSON 输出由调用方 `extractJSON` 兜底。其余 400（鉴权等）不触发，行为不变。
6. **校验对齐 + 选项打乱**：单篇改逐题过滤（结构非法剔除、索引越界剔除、全无效才报错），与原批量口径一致；生成落盘前对每题选项 Fisher-Yates 打乱并重映射 `correctIndices`（存储与会话同源，`removeQuestion` 按内容定位不受影响）——消除模型正确答案位置偏好。
7. **提示词修订**：开头随题型变化（多选不再宣称「每题一个正确答案」）；截断统一 10000 字符（`NOTE_CONTENT_LIMIT`）；追加两条约束——选项不带「A.」类前缀且互不相同、题目答案必须依据笔记内容。
8. **questionsPerNote 钳制**：解析后 clamp 至 1~20（0/无效 = 自动），防无界输入撑爆输出。

## Considered and rejected

- 保留批量协议 + 键匹配校验补偿（错键篇重试）——被拒：为已死的入口修协议不值得，键回显是根因本身。
- 重试做在 core/ai.ts（五域共享）——被拒：对话/摘要域有自己的重试语义与 UX，一处改动全域回归，收益不成比例；quiz 层包装足够。
- 选项打乱挂在「打乱出题顺序」设置下——被拒：位置偏好是生成质量问题，与用户偏好无关，恒开；且挂在会话入口会破坏 `removeQuestion` 按内容定位（存储与 会话不同源）。
- 生成时传 progress 通知删除——被拒：单篇生成 5~20s，保留「正在为 N 篇笔记生成题目… → 原地转结果」动态通知链路（ADR-0010），仅去掉「批量」措辞。

## 存量数据兼容

quiz.json 格式不变，旧题目（未打乱选项）继续可用，消费完自然淘汰；无设置键增删，无迁移。
