# ADR-0128: 娱乐域「小说」正名「书籍」+ 分类池按组隔离（体裁）

日期：2026-09-22 ｜ 票：issues/299-entertainment-book-genre.md ｜ 状态：已接受

## 背景

用户要求：娱乐域中的「小说」改成「书籍」，国家行照旧，「分类」改成「文学」「哲学」「社会学」等（引《中国图书馆分类法》22 大类口径，行标签叫「体裁」），同样支持自行添加；电影/电视剧保持不变。

现状（ADR-0127 之后）：顶级类型固定七项含「小说」；表单行序 类型 → 国家（全局单选池）→ 题材（全局多选池，data.json `entertainmentGenres`，全类型共用悬疑/爱情/年代起步 + 自定义固定）。

用户裁决（票 299，两轮 grill 全推荐）：分类落「题材/体裁」行（非顶级类型细分，不破票 293 的类型冻结）；存量旧 tag 读侧归一不改写 fm；自定义项按组隔离；书籍行标签与展示口径统一叫「体裁」。

## 决策

1. **组正名「小说」→「书籍」**：`TYPE_GROUPS`/`GROUP_ORDER`/`TYPE_COLORS`（色值 `#3aa08f` 沿用）同步更名；`LEGACY_TAG_MAP['小说']='书籍'` 读侧归一（复用票 293 剧集退役先例）——装载时 `typeTag` 归一显示为「书籍」，**fm 原值不改写**（`我的/娱乐/*.md` 零迁移）。豆瓣抓取口径不变：书籍（含旧小说 tag 归一后）不入自动抓取队列。
2. **分类落「题材/体裁」行，不落顶级类型**：文学/哲学/社会学等是条目的多选描述标签（复用 fm 键「类型」，顿号分隔），不是决定归属的顶级类型细分——顶级类型自定义继续冻结（ADR-0127 决策 3 不破）。
3. **题材池按组隔离**：data.json 新键 `entertainmentGenresByGroup`（组 → 自定义段顿号串）；各组自定义项互不可见。默认池按组：书籍=《中国图书馆分类法》22 大类（去顿号规范名——顿号是存储分隔符，类名内不得出现）；其余六组（电影/电视剧/短剧/动漫/纪录片/公开课）保持 悬疑/爱情/年代 不变。未知组回落影视默认。
4. **存量平移语义（虚拟迁移）**：旧全局键 `entertainmentGenres` 在组键缺省时作回落——剔除旧默认三项（`DEFAULT_SETTINGS` 里该键默认值即「悬疑、爱情、年代」，非用户自定义，必须剔除防污染书籍池）后作为「真实存量自定义」对全组可见，与隔离前行为一致；组键一旦写入即以组键为准，回落中读到的旧自定义项随首次写入固化进组键。旧键保留不删。
5. **体裁文案跟随（显示层）**：书籍条目的表单行标签、详情弹窗字段、导出感想卡均显示「体裁」（表单标签带空格风格「体 裁」）；其余组仍「题材」。切类型时行标签与选项池即时跟随重绘（`j-genre-label` 钩子）。fm 键「类型」不变，纯显示层。
6. **AI 推荐跟随**：提示词类型枚举 小说→书籍；`GROUP_DEFAULT_TAG` 加 `书籍:'书籍'`，保留 `小说:'书籍'` 兼容旧模型输出归一。
7. **默认题材池按组改定（同日补充，用户改定，覆盖决策 3 的「其余六组保持悬疑/爱情/年代」）**：影视四组（电影/电视剧/短剧/动漫）共用 剧情/喜剧/动作/爱情/科幻·奇幻/悬疑·惊悚/历史·传记/纪实/动画/其他（10 项）；纪录片专属 历史/人物传记/自然地理/科学科技/社会人文/政治军事/经济商业/文化艺术/美食旅行/体育/犯罪司法/灾难危机/健康医疗/宗教哲学/教育亲子/环境动物（16 项）；公开课=学科门类 哲学/经济学/法学/教育学/文学/历史学/理学/工学/农学/医学/管理学/艺术学（12 项）；书籍维持中图法 22 大类。名单项含斜杠（如「科幻/奇幻」）无碍——存储分隔符仅顿号。旧全局键回落剔除名单（悬疑/爱情/年代）不变——那是 `DEFAULT_SETTINGS` 旧默认值，与新默认池无关。

## 后果

- 命令数不变（无新命令）；smoke 计数不动。
- `EXPECTED_COMMAND_IDS` 无变化；options.test/ui.test/data.test/douban-queue.test 同步改写并新增按组隔离用例。
- 旧「小说」条目在列表/徽章/筛选中显示为「书籍」组，编辑保存后 fm tag 仍为原值「小说」（用户手动改类型才会写新值）——显示归一与数据原值并存，与票 293 同构。
- data.json 新增一键为非敏感配置，不涉密钥治理。
