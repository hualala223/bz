# ADR-0113：日记标题层级整体上提一级（读侧层级无关）

## 背景

ADR-0112 把日程规划改成「按日记模板建文件」后，产物形态与用户的 QuickAdd 宏逐字节一致，基准文件是 `我的/日记/2026-09-11.md`：

```md
## 睡眠相关
## 随笔
## 新闻联播内容记录
## 日常行为记录
## 日程规划

### 代办事项
### 完成情况跟踪
### 备注
```

用户随后提出：**所有标题往前提一级**——二号标题变一号、三号变二号。即骨架由 `##` 提到 `#`、日程三段由 `###` 提到 `##`。复盘模板另给口径：**仅首行「当日复盘」提到一级，其下 `### 触动点` / `#### 描述经过…` 不动**。

难点在于**标题层级是字面量匹配的一部分**：捕获插行（`ACTIVITY_HEADING` / `TODO_HEADING`）与规划判重（`PLAN_MARKER` / `PLAN_TRACK_MARKER`）都按标题整行匹配，改层级就等于改契约。而 vault 里已有存量日记（2026-09-09 模板形态、2026-09-10 条目形态、2026-09-11 模板形态 + 规划），它们的标题仍是旧层级。

用户对两个分叉的裁定：

- **读侧兼容旧层级**（不批量迁移存量文件）——旧日记照常可判重、照常能命中捕获小节；
- **复盘只提首行**。

## 决策

**1. 写侧层级整体上提一级。**

| 位置 | 改动 |
|---|---|
| 日记骨架（模板文件 + `FALLBACK_DIARY_TEMPLATE`） | `## 睡眠相关/随笔/新闻联播内容记录/日常行为记录/日程规划` → `# …` |
| 日程三段（`buildPlanContent()`） | `### 代办事项/完成情况跟踪/备注` → `## …` |
| `PLAN_HEADING` / `PLAN_MARKER` / `PLAN_TRACK_MARKER` | 跟随之改为 `# 日程规划` / `## 代办事项` / `## 完成情况跟踪` |
| 捕获小节标记（`ACTIVITY_HEADING` / `TODO_HEADING`） | `# 日常行为记录` / `## 代办事项` |
| 复盘模板 `REVIEW_TEMPLATE` | 首行 `## 当日复盘` → `# 当日复盘`；`### 触动点` 与其下 `####` **不动** |
| vault 模板真源 `CONFIG/TEMPLATE/模板-日记.md` | 同步提级（4 个消费方随之受益） |

**2. 读侧（判重 / 补写 / 捕获插行）按标题文字匹配，层级无关。**

- 规划判重 `hasPlan(text)`：整行正则 `^#{1,6}[ \t]+{标题文字}[ \t]*$` 命中「代办事项」与「完成情况跟踪」即算已规划——层级不再参与判定。
- 补写判定：`日程规划` 标题同样层级无关，旧文件的 `## 日程规划` 不会被重复插一遍标题。
- 捕获插行 `insertIntoSection`：**两轮查找**——先精确匹配入参标记（新层级），未命中再匹配「多一个 `#`」的旧层级形态；**小节边界取命中行的实际层级**（`headingLevel(lines[markerIdx])`），故旧文件切分口径与改动前逐字一致。
- 文件缺失时的「标记 + 行」起头一律用**新层级**标记。

**3. 存量文件不迁移。** 用户明确不批量改历史日记；读侧兼容已覆盖「旧文件继续用」的需求。新建文件一律新层级，因此库内会长期并存两种层级，这是**有意接受**的状态。

## 后果

- 新建日记的视觉效果符合用户要求：骨架一级、日程三段二级。
- 「当日待办事项」「日常行为记录」两个捕获在存量旧文件上**不退化**（仍命中 `## 日常行为记录` / `### 代办事项`），不出现「未找到小节，已追加到文末」。
- 存量旧文件上再点「日程规划」**不会重复创建**（双标记层级无关命中）。
- 备注：新模板下骨架标题（`# 睡眠相关`）与日记条目标题（`# 📖 HH:mm`）同为一级。解析器/修复引擎按「`#` + emoji + `HH:mm`」识别条目标题（`HEADING_RE` 要求时间），骨架标题无时间戳，**不会被误判为条目标题**，前导区提取与修复检测均不受影响（ADR-0110 口径不变）。

## 备选（未采纳）

- **读侧只认新层级**：存量旧文件上捕获会退化成"整行追加到文末"、规划会被判成"没有规划"而重复创建（用户否决）。
- **批量迁移 vault 内全部历史日记的标题**：用户选择不动历史数据；且宏/其他写方仍可能产出旧层级，迁移不彻底。
- **复盘模板整体提级**：`# 当日复盘` 会与同在一处的条目标题 `# 📖 HH:mm` 撞同级，用户只要求首行提级。
- **把层级做成设置项**：为一个一次性样式偏好引入配置面，收益不抵复杂度。
