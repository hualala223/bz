# 票 298：待办分类器——「类别/优先级/时间」三维组合筛选替换排序下拉

日期：2026-09-22 ｜ 域：todo ｜ 状态：已裁决（grill-with-docs 两轮，全部推荐收口）

## 需求

待办面板原工具行只有一枚排序下拉（紧急优先/仅按到期/按创建）。改为三维分类体系：

- 新增维度「**类别**」：必须 / 想要；
- 新增维度「**时间**」：紧急 / 不紧急（手动标记，与截止时间 due 无关）；
- 与既有「**优先级**」（重要/次要）做 2×2×2 = 8 组合分类（如「必须/重要/紧急」「想要/次要/不紧急」）；
- 分类器**替换**「紧急优先」排序下拉的位置，选中某组合即筛选显示对应待办。

## 裁决记录（grill 两轮）

| 决策点 | 裁决 |
|---|---|
| Q1 时间字段来源 | 独立标记字段（urgent/not），不从 due 派生 |
| Q2 旧数据缺省 | 必须 + 不紧急（must + not），零迁移 |
| Q3 录入点 | 仅创建/编辑弹窗：类别行在优先级行**上方**、时间行在**下方**（参照优先级 uiChoice 形态）；composer 不加 |
| Q4 分类器形态 | uiSelect 下拉（9 项：全部 + 8 组合），标签「必须/重要/紧急」式 |
| Q5 排序去留 | 排序下拉撤销；「按到期」「按创建」并入分类下拉末尾作第 10/11 项（选中 = 全部 + 该排序）；「紧急优先」排序退役，其排序逻辑（到期优先 + 重要优先）保留为内部默认排序 |
| Q6 重要伪场景/star 切换 | 全部保留不动 |
| Q7 记忆 | 每次打开面板重置「全部」，不持久化 |
| Q8 卡片标记 | 不加，卡片视觉不动 |

## 实现

- 数据：`TodoItem` 增 `category`（must/want，缺省 must）与 `urgency`（urgent/not，缺省 not）两字段，`normalizeItem` 归一补默认，memo.json 旧数据零迁移（14 字段 → 16 字段）。
- 状态：`M.sortMode` → `M.filterMode`（'all' / '<category>-<priority>-<urgency>' / 'due' / 'created'）；排序逻辑复用：due/created 沿旧语义，其余（all/组合）走原 priority 排序。
- 面板：排序下拉 → 分类下拉（11 项）；打开恒「全部」；录入置顶（pinnedNewId）放行扩展到组合筛选。
- 编辑器：类别/时间两枚 uiChoice 夹住优先级行；composer 落盘条目写缺省值。
- 设置：todo 设置页「默认排序方式」行移除（memoSortMode 键退役保留兼容）；设置面板原型演示数据同步。
- 体检双链同步：`MEMO_ITEM_FIELDS` 16 字段、`checks-consistency.memoNormalize` 快照加同款两行（契约：与 normalizeItem 逐字对齐）。
- 卡片/日记投影/file-sync/检查四之外的链路零改动。
