# 交互协议（共享）：动态多轮启发 + 素材请求 + A/B/C 自动扩展

本项目写作类 skill（story-openbook / story-character-lab / story-scene-card / story-style-spec / story-final-check / story-long-write）统一挂载本协议：凡出现「启发」「素材请求」「自动扩展模式」字样，均以本文件为准。交互总原则：**决策权归人，执行归 agent；展示 → 等待 → 用户明确通过才进下一步**。

来源：《小说设置提示词》G1 全局机制（G1.md L241-296 等），已在各 skill 按门落地，此处集中为共享规范。

## 1. 卡壳信号识别（用户何时算「没想法」）

出现以下任一表述即进入启发循环（不再追问同一问题）：

| 类别 | 用户表述示例 |
|------|-------------|
| 直接表达 | 「没想法」「不知道」「再给点例子」「换一批」 |
| 模糊表达 | 「嗯……」「让我想想」后长时间无回应 |
| 跳过请求 | 「先不说这个」「下一个」 |

`「你来定」` 是特殊信号：不进入轮换，直接基于上下文做最优选择并请用户确认。

## 2. 八维启发维度池（轮换规则）

每轮从**不同**维度切入，维度选择基于当前决策点性质；禁止连续两轮重复同一维度。

| 维度 | 适用场景 | 生成策略 |
|------|---------|---------|
| 量化推演 | 篇幅、节奏、数量类决策 | 把抽象感觉转成数字（章节数、字数、时间、密度） |
| 对标作品 | 篇幅、风格、结构 | 引用知名作品作参照，解释其参数 |
| 经典母题 | 主题、原型类决策 | 从母题库提取与当前故事契合的原型 |
| 高概念混搭 | 题材、设定类决策 | 把两个不相干概念并置/嵌套/化合 |
| 角色视角 | 人物、关系类决策 | 从某角色视角反推其会做什么 |
| 意象与感官 | 命名、细节、锚点类决策 | 用五感触发具体细节与画面 |
| 极端情境 | 冲突、代价类决策 | 假设极端后果，检验选择强度 |
| 反向假设 | 一切决策 | 假设与直觉相反的方向，对比取舍 |

典型轮换示例（篇幅类）：量化推演（每日可写字数×周期反推）→ 对标作品（体感参照表）→ 经验建议（按写作经验分档）→ 兜底。

## 3. 轮次管理与终止条件

- 每轮结束明确询问：「这一批有让您产生想法的吗？还是我换个角度再给一批？」
- **连续 3 轮未做出选择** → 主动提议采用当前最优占位方案（默认值），请用户确认。一旦同意即继续，不空转等待。
- 用户随时可说「你来定」→ AI 基于上下文做出最优选择并请用户确认。
- 记录前确认话术：「您确定采用 [具体内容] 吗？确认后我将更新产物并继续。」
- 占位方案必须在展示中标 `[占位待复核]`，用户可随时回头修改；后续门若发现占位导致不一致，列为 pending 项。

## 4. 素材请求机制

- **触发时机**：进入关键数量/结构决策（如篇幅、密度、数量参数）前，必须先问一次能否提供参考素材（对标作品、节奏参考、性格词典、幽默技巧词典等——按门差异化话术）。
- **请求话术模板**：「如果您有 [决策点] 的参考素材（如对标作品/风格样本/词典），可以现在告诉我；没有的话我将基于 [当前已知上下文] 提供推荐值。」
- **处理规则**：
  - 提供 → 确认接收，提取核心借鉴元素，标注「【素材参考：借鉴了 XX 元素】」；
  - 未提供/跳过 → 回复「好的，我将基于现有设定继续推进」，立即进入量化推演或默认值推荐；
  - **禁止**：用户未提供素材时假装有素材或编造来源。

## 5. 自动扩展模式 A/B/C（`_meta.auto_expansion_policy`）

| 模式 | 行为 | 适用 |
|------|------|------|
| A 手动 | 每个决策点都停下等用户确认，不自动推进 | 用户希望全程掌控 |
| B 智能自动（默认） | 确定性计算（公式）直接执行；草案类先展示再确认；仅关键决策点停下 | 大多数会话 |
| C 全自动 | 全部按占位默认推进，仅给出摘要，用户事后复核修改 | 用户明确要快 |

- 未声明时默认 **B**；用户说「快速模式」→ 按 C 的推进程度处理并明示「快速模式已生效」。
- 与 story-stepwise 确认门叠加时：即使模式为 C/B，**stepwise 门仍必须停**（stepwise 优先级更高，除非用户同时说「快速模式」）。
