# 逐步确认模式

用户要求：**从选题到每一章正文，每一步都必须经其确认后才继续。** 本模式对同会话内 `story-long-write`、`story-scene-card` 等写作类 skill 生效；与其自身默认停靠策略冲突时，**以本模式为准**。

> **全流程步骤地图**：全书从立项到完本的九阶段（立项→开书→文风精化→约束清单→人物→大纲→正文→体检→审查去味→发布）与每步触发词，见 `references/book-roadmap.md`（唯一权威）；本门表与之对齐。

> 交互通用规则（卡壳信号/八维启发/3 轮终止/素材请求/A-B-C 模式）见 `references/interactive-protocol.md`（共享协议）；门名「卷门/纲门」随提示词组（G4/G5）与 stepwise 门名去歧义，避免互相撞名。

## 确认门（逐草案确认，非要点式）

| 门 | 时机 | 停下展示什么（展示的是已落盘草案，确认的是「是否照此继续」） | 确认粒度 |
|----|------|---------|---------|
| 选题门 | Phase 1 完成 | 题材方向 + 核心情绪 + 目标体量建议（总字数/总章数） | 逐项展示三行摘要 → 全部确认或逐项改 |
| 锚定门（开书四锚定） | 开书 OB-3~OB-3.7 完成 | ①时间/地点/背景锚定（起点时间·跨度·推进规则·核心空间层级·时代社会背景）②文风锚点（关键词·锚点语·句长标点基调）③平台与读者画像（平台·规则·画像·四维适配）④主角情感关系基调（单/多/无 CP·占比·捆绑度） | 四项逐门确认（每门草案→确认→锚定）；加载 `story-openbook` 时由 OB-3/3.5/3.6/3.7 覆盖，不再重复停下；锚定产物为约束清单 A 类硬约束，先于大纲 |
| 人物门 | Phase 2 完成 | 主要角色卡（身份/动机/金手指/关系）+ 世界观骨架 | 逐角色草案（每人一份简卡）→ 逐人确认 |
| 体量门 | 体量总览完成 | 总章节数、目标字数、四阶段章号区间、小中大高潮章号、四张约束表确认位 | 数字表逐行确认；**四张约束表（`{书名}/大纲/_约束表.md`）在此设确认位**——character_chapter_map / character_arc_beat_map / worldview_conflict_schedule / theme_beat_schedule 逐张展示摘要，逐张「确认/改/跳过该表」；建表模板与生成步骤见 `story-long-write/references/workflow-setup.md`「四张约束表」节 |
| 卷门（原 G4） | 每卷卷纲完成 | 该卷功能 / 约多少字多少章 / 核心事件 / 爽点蓄力链（TP-XX 行） | **逐卷草案完整展示**（一次一卷，确认才进下一卷）；卷末钩子+卷内三幕章号单独确认 |
| 纲门（原 G5） | 每批细纲完成 | **逐章草案（非一行摘要）**——每章展示：α点（目标→障碍→代价+情绪弧线）/ 爽点五字段（角色/类型/级别/蓄力目标/蓄力进度）/ 关系变化（前→后）/ 结尾钩子设定（chapter_question + hook_chain_status）/ 环境与氛围 / 伏笔·象征·世界观体现 / 事件素材数校验结果 | 本批 ≤10 章，**逐章确认六块**（对齐 G5.2 第一~七步）：①α点戏剧性深化 ②爽点同步编织 ③关系变化铺垫与引爆 ④钩子与衔接设计 ⑤环境与氛围设计 ⑥事件展开性校验（补充事件库自动补足 S）；执行「最小字段集」档的章节可合并为一行速览+α点单行确认 |
| 场景门 | 场景方案确定 | 每场景（情绪标注+类型分配：对话/动作/内心/过渡）+ 容量规划三件套确认值（详细比例/高张力密度/幽默档） | 逐场景草案 → 逐场景确认 |
| 写前门 | **每章动笔前** | 本章意图一句话：目标情绪 / 核心事件 / 字数目标 / 出场角色（对照卷门/纲门已确认内容，不一致时停下问） | 单项确认即可（此门不重复细纲全文） |
| 章后门 | **每章落盘后** | 字数 vs 目标、去AI味 blocking 是否清零、追踪事务是否已提交、（每 3 章）快照校验结果 | 逐项报告 → 用户通过才进下一章 |

## 规则

- 每道门：展示 → 等待 → 用户明确通过才进下一步；要改就改完只重示该门。除用户明说「这步你定 / 跳过」外，不存在静默通过。
- 日更批量在确认模式下自然变为**逐章推进**：写前门 → 写 → 章后门 → 下一章写前门。
- 全文草稿在展示前已落盘；确认的是"是否照此继续"，不是让用户重新审全文。
- 用户说「快速模式」即解除本模式，仅保留各 skill 自带停靠点（停细纲交付、单轮 ≤3 章）。
- **启发兜底**：任何门内连续 3 轮出不了令你满意的方案 → 采用当前最优占位方案并在展示中标 `[占位待复核]` 继续推进，不空转等待；你随时可回头修改（详见 interactive-protocol.md 第 3 节）。
- **六块校验落地**：纲门逐章确认时按 G5.2 九步顺序增量产出（第零步约束摘要 → 一~七步六块 → 第八步完整草案确认），已实现的字段定义（α点/爽点五字段/素材数校验/节奏检查）以 `story-long-write/references/workflow-setup.md` 为准，此处只定确认节奏不定字段。

> 设计意图：决策权归人，执行归 agent。本模式只规定"哪里必须停下来问、问到什么粒度"，不干预"怎么做"；章后门同时充当防遗忘检查位——追踪未提交不算本章完成。
