# 开书确认门决策点表（来源：《小说设置提示词》G1-G2）

本文件是 `story-openbook` 的决策点权威：每个确认门的字段、默认值、公式与启发维度均以此为准，交互时按门逐项确认并累积进 `设定/_开书.json`。数值来自用户《小说设置提示词》，均为默认参考值，可在用户确认时覆盖。

## 全局规则（沿袭提示词）

- **自动扩展模式**（`_meta.auto_expansion_policy`）：A 手动 / B 智能自动（默认）/ C 全自动。
- **JSON 累积**：每门输出完整累积 JSON，禁止 `...`、`// 同上`、`略`；修改进 `_meta.modifications`；依赖未决字段置 `null` 并登记 `pending_fields`。
- **受阻恢复**：`blocked_at_<门>` + 缺失字段报告。
- **启发维度池**：经典母题 / 高概念混搭 / 对标作品 / 角色视角 / 意象感官 / 极端情境 / 反向假设 / 量化推演。每轮换一个维度，3 轮无选择 → 占位默认。

## OB-1 灵感与篇幅（G1.0/G1.1）

| 决策点 | 启发维度轮换策略 | 兜底默认 |
|--------|------------------|----------|
| （G1.0 热身，可选）创意热身与写作习惯 | 意象/感官（自由联想）→ 经典母题 | 跳过不阻塞；执行则 7 天习惯跟踪建议 |
| 自动扩展模式 | 对标作品 → 量化推演 → 角色视角 | `"B"`（智能自动） |
| 目标总章节数 | 量化推演（每日可写字数×创作周期反推）→ 对标作品（章节数参照表）→ 经验建议（新手 40-60/有短篇经验 80-120/有完本经验 150+）→ 兜底 | 60 章（中篇入门起点） |
| 每章预估字数 | 常见档位对比表（2000 快节奏/2500 平衡/3000 高密度/4000+ 深度）→ 量化推演（更新习惯）→ 直接确认 | 2500 字/章 |
| 总字数与篇幅档位（自动联动） | 由两项确认值自动计算，档位标准照提示词原文 | 短篇 ≤60 / 中篇 61-150 / 长篇 151-500 / 超长篇 ≥501 |
| 项目暂定名称 | 主角标签法/核心意象法/类型关键词法 → 直接使用日期戳 | （**本字段在 OB-1 仅占位登记，不在本门定名**；正式定名与建目录由 OB-1.5 书名门承接）`项目_YYYYMMDD` |

- **素材请求（按门差异化话术）**：进入章节数决策前先问「有没有心仪的对标作品（如希望篇幅类似《XXX》）或章节节奏参考？没有就直接答下面的问题。」若用户透露对标/更新习惯，据此调整推荐值（如对标《三体》三部曲 → 推荐约 90 章）。
- **篇幅三连闭环（本门强制）**：① 总章节数确认 → ② 每章字数确认时**联动预览总字数**再确认 → ③ 自动计算总字数+篇幅档位后，以表格展示（总章节数/每章字数/预估总字数/篇幅档位），确认后落 JSON。任一环节用户改数 → 重算预览再确认；「没想法」→ 按启发维度轮换（先量化推演问更新习惯，再对标参照表，再经验建议，4 轮内兜底 60 章）。
- **落盘字段**：`length_params.total_chapters`、`length_params.words_per_chapter`、`length_params.total_words`（万字×1 位小数）、`length_params.volume_tier`（短篇/中篇/长篇/超长篇）——**这四字段是全局篇幅唯一标准，后续 OB-4 分卷、Phase 3 体量总览、细纲 S 公式全部引用**。

## OB-1.5 书名（暂定名）与目录创建

> **定位**：书名从「顺手记个字段」升格为**独立确认门**——书名是网文第一道筛选（番茄系「书名决定 80% 流量上限」），须先于大纲/人物/正文定下暂定名，据此约束开篇与简介（书名/简介/开篇三位一体），并**创建 `{书名}/` 目录包裹后续全部产物**。在 OB-1 篇幅三连完成后、OB-2 故事蓝图前执行。

| 决策点 | 启发维度轮换策略 | 兜底默认 |
|--------|------------------|----------|
| 暂定书名 | 用 `story-long-write/references/genre-readers.md`「书名命名技法」生成 A/B 方案（身份法/核心意象法/类型关键词法/平台起名差异）→ 对标作品书名 → 用户选定 | 若用户不选，用「主角标签 + 类型关键词」组合兜底，标 `[暂定]` |
| 书名与卖点一致性 | 反向假设（「读者看到这书名，能 3 秒知道是什么故事吗？」）→ 对标作品 | 书名须点明题材/金手指/钩子之一，禁止文艺悬空（见 genre-readers「书名 3 秒抓人」） |
| 目录创建 | 据 `book_title` 建 `{书名}/`（中文/空格安全名）→ 写 `.active-book` 指针指向该书目录 | 目录名=书名；含 `/ \ : * ? " < > |` 等非法字符时替换为安全字符并回写 `book_title` 备注 |

- **落盘**：`_开书.json` 增 `book_title`（暂定名）+ `book_dir`（目录名）；创建 `{书名}/` 目录；项目根写 `.active-book` 指向 `{书名}/`。
- **目录包裹（硬规则）**：本门之后，`设定/`、`大纲/`、`正文/`、`追踪/` **一律落进 `{书名}/` 目录**，严禁在项目根裸放（与 `AGENTS.md` 文件结构一致）。
- **书名只定名、简介留发布**：开书期只定 `book_title`；简介（吸量文案）依赖成稿卖点，仍由发布阶段 `story-release-package` 产出。
- **改书名**：后续确需改书名，走跨产物修订门禁，并同步重命名 `{书名}/` 目录与 `.active-book` 指针。

## OB-2 故事蓝图（G1.2）

## OB-3 定位（G1.3，含四锚定门之「时空背景锚定」）

| 决策点 | 启发维度轮换策略 | 兜底默认 |
|--------|------------------|----------|
| 题材主类型 | 基于 `core_conflict` 推荐 → 高概念混搭案例 → 对标作品类型标签 | 外部冲突多→奇幻/科幻；内心冲突多→文艺/悬疑 |
| 基调 | 基调光谱对照 → 同一事件不同基调写法对比 → 幽默类型详解 | 从 `core_conflict` 情感色彩推断 |
| 腔调 | 经典腔调案例 → 与基调匹配推荐 → 人称/视角选择 | 第三人称限知 + 冷静克制 |
| **时间锚定**（起点/跨度/推进跳跃） | 对标作品时空设定 → 量化推演（按篇幅档位推时间跨度）→ 意象/感官（用时代细节触发起点选择） | 起点取「当代/近未来/古代/架空」草案 2-3 组带叙事理由；跨度按档位（短篇≤1 年/中篇 1-10 年/长篇 10-30 年/超长篇 30 年+）；推进默认逐章连续、跨卷允许跳年并季节校准 |
| **地点锚定**（核心空间/层级/联动） | 从 `core_conflict` 推断空间类型（封闭/都市/荒野/权力中心…）→ 空间叙事功能分配 → 对标经典场景 | 生成 2-4 个核心地点草案（叙事功能/画面感/关键事件预告）供选择，确认空间层级（安全屋/中转地/权力中心/荒野）与移动路线；标注地点×时间、地点×背景联动约束 |
| **背景锚定**（时代/社会背景） | 从 `core_conflict` 推荐（如制度腐败→当代或近未来社会转型期）→ 意象/感官 → 反向假设 | AI 推荐草案，交互确认后填 `setting.time_period`、`setting.social_background`，并与地点互证（「这个背景 + 这个地点」组合成立） |
| 多时间线规章（若适用） | 穿越/重生/快穿 → 各线起点/汇合点/规则冲突处理 | 单时间线则不填（置 `null`）；多时间线则逐线确认 |
| 追踪双时间线初始化 | 作者时间线=章节推进、读者时间线=发布节奏 → 明确映射 | 由时间锚定自动生成映射草案供确认 |
| 核心场景 | 场景功能组合推荐 → 意象词汇联想 → 对标经典场景 | 生成 3 个场景草案供选择 |
| 核心受众与读者契约（含主角代理权/期待债） | 从 `core_conflict` 提取承诺关键词 → 契约设计 → 对标悬念模式 | 自动草拟 `reader_contract` + `target_audience`；补原版强字段：`protagonist_agency`（主角因果权+结算权）、`core_debt`（开篇必须偿还的核心期待债），参 `story-long-write/references/reader-contract-and-progression.md` |
| 核心悬念引擎（countdown） | 倒计时类型匹配（时间锁/资源锁/空间锁/信息锁/关系锁）→ 起点/终点章建议 → 对标作品模式 | 自动草拟 `countdown.global`（类型/说明/起点章/终点章/失败后果/呈现方式） |
| 对抗性确认 | 对抗层级与心结匹配 → 极端情境 | 按公式自动计算层级数 |
| 幽默元素配置（若适用） | 询问是否包含 → 追问类型 | 基调不明确含幽默则默认为无 |

产出字段：`genre_tone`（genre/tone/voice）、`setting`（`time_period` 年代 / `social_background` 社会背景 / `locations` 地点数组，每地点含 `narrative_function`、`description`、`key_events`）、`setting.time_anchor`（start_point/span/progression_rules/timeline_layers/tracking_init）、`setting.place_anchor`（core_locations/narrative_functions/spatial_hierarchy/location_time_links）、`target_audience`、`reader_contract`、`protagonist_agency`（因果权/结算权）、`core_debt`（核心期待债）、`countdown.global`（全局倒计时：类型/说明/起点章/终点章/失败后果/呈现方式）、`humor_reader_contract`、`humor_config_early`（苦笑转化目标高/中/低、笑点密度、幽默与主题关联、技巧、主角/叙述者幽默风格、苦笑转化锚点）。

> **时空背景锚定（先于大纲，三要素齐备，地点不丢）**：本门「时间锚定 / 地点锚定 / 背景锚定」三项在 OB-3 内完成并锚定，**不得推迟到大纲设计阶段**；锚定产物（`time_anchor`/`place_anchor` + `设定/世界观/背景设定.md`+`地理.md`）成为约束清单 A 类硬约束，大纲只消费不漂移，确需修改走跨产物修订门禁。

## OB-3.8 对抗层级与副线结构（先于主题/世界观/人物/大纲，独立确认门）

> **定位**：`对抗层级 N` 与 `副线数 S` 从 OB-4「长度自适应参数」汇总表中**拆出独立成门**，单独逐项确认——因为它们是被下游硬消费的结构参数：N→主题价值阶梯层级（OB-5）、世界观规则数（OB-6 `X=…+N…`）、人物反派四档（`villain_tier` 档位数）、粗纲转折点映射（`antagonist_level`）、细纲 α点对抗表现；S→人物关系网络与粗纲/细纲副线编排。**在篇幅（OB-1）与故事蓝图（OB-2）之后、主题（OB-5）之前确认，保证下游有数可用。**

### 一、对抗层级 N

| 决策点 | 启发维度轮换策略 | 兜底默认 |
|--------|------------------|----------|
| 对抗层级数 N（数值） | 量化推演（篇幅档位能否撑起 N 层对抗）→ 对标作品（同篇幅对抗复杂度）→ 经典母题（核心冲突需要几层对抗） | 档位公式 短篇 1-2 / 中篇 2-3 / 长篇 3-4 / 超长篇 4-5 层；交叉 `max(2, min(12, 1 + floor(C/50)))`，取二者中更贴核心冲突者，用户可覆盖 |
| 每层对抗性质与价值对应 | 经典母题（物理→人际→制度→存在四层上升）→ 角色视角 → 极端情境 | 第 1 层=正面价值对立（相反价值）、第 2 层=矛盾价值、… 第 N 层=否定之否定（终极黑暗），逐层与 OB-5 价值阶梯对齐 |
| 每层承接角色占位（谁是该层主对抗） | 角色视角 → 对标作品 | 开书阶段仅占位（「待人物设计」），注明将映射到 `villain_tier`（最终Boss=N 层、大弧Boss=N-1 层…）；真正定人由 story-character-lab 承接 |

- **判断显式化**：给 N 结论前输出「标准（篇幅档位→层数基线）→ 本案例匹配（核心冲突复杂度/题材）→ 结论」，不得直接给数字。
- 产出字段：`length_params.antagonist_layers`（数值）+ `antagonism_structure`（数组：每层 `level` / `nature` 性质 / `theme_value` 对应价值 / `villain_role_placeholder` 占位 / `chapter_budget` 章数预算 / `consumed_by` 下游声明）。

## OB-4 篇幅自适应与分卷（G1.4/G1.6）

| 决策点 | 启发维度轮换策略 | 兜底默认 |
|--------|------------------|----------|
| 长度自适应参数（角色各层数/伏笔/钩子/场景数；对抗层级与副线已拆至 OB-3.8） | 展示计算草案 → 增减某层级的叙事影响 → 对标配置参考 | 按 G1.4 公式集计算（见下） |
| 自动分卷（卷数 V + 各卷章数分配） | 分卷逻辑对比（按节奏/地点/人物视角）→ 对标作品分卷 → 兜底采用草案 | `V = max(1, ceil(C/目标每卷章数))`，余数均分法分配各卷章数 |
| 卷内三幕与卷末钩子 | 卷核心功能生成标题公式 → 钩子类型详解（悬念/情感/动作/揭示）→ 画面描述选项 | 按 25%-50%-25% 划分卷内三幕，钩子类型自动填充 |
| 卷级倒计时 | 全局倒计时分解 → 微型倒计时生成 | 每卷 `countdown.per_volume` 分解或自立微型倒计时 |
| 关口回填（分卷后） | 关口一章号是否落在第一卷/最后两卷 → 提示调整 | 调整 `three_act_seeds` 关口位置并记录待 G1.7 进 modifications |

**G1.4 公式集（对齐提示词原文，总章节数 C；对抗层级与副线已在 OB-3.8 确认，此处仅引用不再重算）**：角色总数 `C×0.3`（取整）；核心角色 `max(3, floor(C/20))`；重要配角 `max(4, floor(C/15))`；功能角色 `max(2, floor(C/25))`；背景角色组 `max(1, floor(C/30))`；核心伏笔 `max(3, floor(C/15))`；中期线索 `max(2, floor(C/20))`；每章钩子数 按篇幅档 1-2/1-2/2-3/2-4 个；每章场景数 2-3/2-4/3-5/3-6 个。

**分卷算法**：目标每卷章数 短篇不分卷或 1 卷 / 中篇 30-50 / 长篇 40-60 / 超长篇 50-80；`V = max(1, ceil(C/目标每卷章数))`；余数均分法：基础章数 `floor(C/V)`、前 `C%V` 卷各多 1 章。

**合理性检查（G1.4 第四步，5 项必查）**：①核心角色数 3-8 人（超长篇除外）；②副线数 S ≤ 核心角色数（S 由 OB-3.8 已确认，此处校验）；③核心伏笔平均每卷 2-4 个；④每卷章数在目标范围 ±20% 内；⑤核心场景数 ≥ 卷数。出现 ⚠️ 询问是否调整，用户可忽略。

产出字段：`volume_structure`（total_volumes/各卷章数与定位/卷末钩子）、`three_act_seeds.volume_mini_acts.volume1`（第一卷三幕连贯文本）、`countdown.per_volume`。
