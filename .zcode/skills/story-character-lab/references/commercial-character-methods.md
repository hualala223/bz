## 一、注入于 G3.0（框架搭建）

### 1. 向人设深化 vs 向故事深化（框架期判断）

| 条件 | 优先方向 | 执行动作 |
|---|---|---|
| 主线已复杂、多势力、多反转 | 向人设深化 | 结构保持简单，在人物欲望/反差/关系互动上制造新鲜感 |
| 主线过直、人物鲜明但事件不足 | 向故事深化 | 增加阻碍/目标变化/信息差/代价，不新增无功能角色 |
| 短篇/轻量篇幅 | 向人设深化 | 用 1-2 个强人设标签驱动冲突 |
| 长篇关键卷/高潮卷 | 两者结合 | 故事升级一个维度 + 关键关系发生可见变化 |

### 2. 人设关联分层（强/中/弱）

| 层级 | 定义 | 功能 | 数量要求 |
|---|---|---|---|
| 强关联 | 直接影响剧情走向和核心梗爽点的设定（实力/钱财/人脉/背景） | 推动人物碰撞、剧情推进 | **每个角色至少 3 个** |
| 中关联 | 配角的强关联设定（不抢主角风头） | 功能性与辨识度 | 适量 |
| 弱关联 | 个人偏好设定（喜欢蛋糕/爱好看美女） | 真实感与记忆点 | 不限 |

执行：主角把影响剧情走向的属性归强关联；弱关联不喧宾夺主（强关联才是延伸剧情的核心）。

### 3. 人设 ≠ 人物设定表

- 人物设定表 = 身高/外貌/家庭背景等信息堆砌（外在信息）
- 人设 = 围绕「灵魂/特殊人格」的功能性设计，以人格驱动行为
- **检查**：只有身高体重爱好、没有「灵魂/特殊人格」的功能性设计 → 重做。

## 二、注入于 G3.1 主角

### 1. 三层标签反差人设法（第四步·性格内核）

| 层 | 名称 | 含义 |
|---|---|---|
| 身份标签 | 外界看到的身份 | 豪门弃妇 |
| 表现标签 | 展现给外界的行为 | 隐忍不发、逆来顺受 |
| 内核标签 | 真正内心 | 冷静、有计划、步步为营 |

执行：三层之间必须制造反差（反差=立体感）；身份/表现可相似强化刻板，**内核必须反转**；反差越大「亮牌时刻」越震撼；每重要角色至少一层反差；**用行为对比体现，不要旁白描述**。

### 2. 行为反差进阶（关系进入亲密层后）

- 检查角色所处关系阶段；行为反差本身是人设一部分，必须写进剧情
- **行为退化 = 感情深化**：身份期爱调戏主角的辣妹，进入亲密后反而不敢表白
- 亲密阶段不要维持早期行为，否则反差失效

### 3. 主角红线表（绝对不写）

| 禁止 | 原因 |
|---|---|
| 圣母型主角 | 读者要痛快而非说教 |
| 无脑战斗机器 | 难共鸣 |
| 内核邪恶 | 无法代入 |
| 因蠢/圣母犯错 | 无法原谅 |
| 自暴自弃 | 比被欺负更厌恶 |

可原谅的错 = 因不可抗力/信息差导致；与实力不匹配的犯蠢不可原谅。

### 4. 动机链 CICR 模板（第五步·动机）

```
起因 Cause → 角色经历了什么（必须具体：「众目睽睽下被打耳光」优于「被欺负」）
意图 Intent → 角色想做什么
约束 Constraint → 什么阻碍他（必须有力，否则一路碾压无张力）
风险 Risk → 失败代价（必须真实）
```

动机冲突四类型（内心挣扎用）：目标 vs 道德 / 情感 vs 利益 / 短期 vs 长期 / 自我 vs 他人。
动机必须情感驱动（「为母复仇」优于「成为最强」）；可演变但不能说变就变。

### 5. 代入感构建法（全程，网文命门）

- **核心**：节奏和情感链条不断裂；断裂标志 = 读者开始用现实逻辑评判情节
- 方法：共情切入点（日常事件）/ 细节真实性 / 救猫咪情节（开头强化人设某方面）/ 暴露弱点困境 / 合理化虑点（「缺钱」天然共情）
- 共情三层次：表层=经历类似 / 深层=情感类似 / 认同感=价值观一致
- **破坏代入感**：角色做出读者无法理解的选择、大段设定说明打断、节奏拖沓、主角三观与目标读者严重偏离

### 6. 主角逼格 / 压势不压人 / 调子起太高（第六步·外在）

- 主角必须有逼格（代入基础）；可不完美，但不能让人看不起
- **调子起太高的化解**：压势不压人（压下气势与期待，不打压能力尊严）/ 留维度差距（某维强、他维短板）/ 超额收获法
- **靠山过度红线**：禁止为紧张题材主角设随时可解危机的强力靠山（安全感拉爆=危机感消失=核心情绪偏移）
- 开篇立人设：通过选择建立；智斗型开局比暴力型更易立人设；「聪明但普通」比「上来无敌」易代入

### 7. 主角特质深化（金手指绑架 + 以梗为中心）

- **金手指绑架人设**：金手指不只给超能力，目的是让主角性格合理化；用规则绑架行为 → 配角反应自然塑造形象 → 不需旁白夸品格
- **以梗为中心**：单一标签「杀伐果断」太模糊 → 用具体梗建设（配角见主角成功「你真该死啊」= 强记忆点+趣味）

### 8. 人物记忆点 + 行为重复点

- 每人至少一个性格特质特别突出；目标：剧情不推进时几个人聊天都好看
- 行为重复点：抓住一个行为特质反复写（维持长篇不歪的关键）；反派/配角也需重复看点

## 三、注入于 G3.2 最重要反派（最终 Boss）+ 反派四档

> **反派四档层级表（原版独有，重要缺口）**：G3.2 只设计「最重要反派（=最终 Boss）」；融合后，对抗侧所有角色按冲突规模分四档，各档用原版标准设计，G3.2 管最终 Boss 档。

### 1. 反派四档层级表（仅对抗侧 · 正交于五层结构）

| 档 | 出场篇幅 | 功能 | 设计标准要点 |
|---|---|---|---|
| 小反派 | 1-5 章 | 单个小弧线的障碍 | 1-2 个鲜明特征（嚣张/贪财/欺软怕硬）；干脆退场 |
| 中等反派 | 10-30 章 | 一卷的主要对手 | 动机合理（非纯坏）/ 手段（武力/权谋/资源）/ **至少赢主角一次** / 正面击败有爽感 |
| 大弧 Boss | 一卷或数卷 | 一个阶段的核心矛盾 | 完整人弧＋自有逻辑 / 与主角**理念冲突**（不只利益）/ 至少一场绝境对决 / 有「恨不起来」的侧面 / 有仪式感终战 |
| 最终 Boss | 全书 | 核心矛盾具象化 | 从第一章就埋伏笔 / 直接对立主角目标 / 碾压主角须蜕变 / 有信念非疯子 |

对应关系（五层×四档正交）：最终 Boss=L1 对抗（C02，G3.2）；大弧 Boss=部分 L2 对抗（C04/C06…）；中等反派=L3 对抗（M10…）；小反派=L4 对抗（F10…）。**支持侧不设反派档**（导师/盟友不套「反派」语义）。

### 2. 反派建立四要素时序

1. **实力展示**——出场即展示实力或手段
2. **动机可信**——从反派视角行为说得通
3. **真实威胁**——至少赢主角一次
4. **终极意图时机**——真实目的留到关键反转点

### 3. 反派性格确立四步法

| 步 | 操作 |
|---|---|
| 1 反派也有梦想 | 反派眼中他是自己故事的主人公 |
| 2 挖掘创伤性过去 | 谁抚养？谁爱？谁伤害？避免什么痛苦？ |
| 3 磨练性格缺陷 | 逆境时不调动积极特质而磨练缺陷——「优势」本身就是致命缺陷 |
| 4 反派是主角的镜子 | 反派长处反映主角弱点，相反=每次相遇必摩擦 |

### 4. 反派渲染公式 + 立体 vs 扁平

- 渲染公式：明确动机 → 动机驱动行为 → 行为形成障碍 → 障碍强度来自反派分量；障碍从人设来，不是故意给主角制造障碍
- **立体 vs 扁平**：不是所有角色都要立体化；扁平反派保持神秘性反而更恐怖；「洗白弱三分，黑化强三倍」；高手被立体化反而变弱
- 反派智商/实力决定主角含金量——反派弱=主角赢没意义；禁止降智送赢
- 反派人设主角化：把反派当主角写；换地图时用新地图衬托旧角色含金量

## 四、注入于 G3.5（重要·支持）/ G3.6（重要·对抗） 重要配角

### 1. 配角功能化 + 白手套角色（复合型）

白手套功能：替主角说话（主角不适合说的）/ 替主角发狠 / 绝对维护 / 粗中有细 / 适时搞笑。
设计原则：光环比主角弱一点；惊艳出场；对主角的质疑第一时间反驳。

### 2. 配角执念设定法

- 给角色一个执念 → 所有行为/爱好/性格围绕执念
- 不需每次贴执念，不写冲突即可，关键时揭示
- 过度极端的执念 → 加「亲民」小细节便于认同
- 适用支线配角（不适合频繁出场的主要配角）

### 3. 人设关系四阶段（亲密度刻度）

| 阶段 | 了解程度 | 表现 |
|---|---|---|
| 相遇（陌生人） | 只知道外表 | 警惕/设防 |
| 相识（过客） | 初步了解不知底线 | 察言观色/阿谀奉承 |
| 相知（好哥们/闺蜜） | 知道秉性底线 | 聊骚/倾诉 |
| 相恋（爱人） | 了解内心伤疤 | 占有欲/喋喋不休/任劳任怨 |

### 4. 出场频率 + 退场规划

- 高人气角色出场频率每 3-5 章一次，每次必须有新信息/新功能
- 读者不感兴趣的角色该舍弃就舍弃，自然下线
- 配角退场主动规划，不能写着写着忘了
- 同一场景配角不超过 3 个有台词

### 5. 群像写作 + 角色池编织

- 每个角色出场都有功能，无水分；功能不明确的角色不要出场
- 角色池编织：以角色带角色（女主讨喜→写女主爸妈/闺蜜→喜爱延续），像网一样编下去
- 不同角色不同说话风格和行为特征；通过行为而非旁白展示

## 五、注入于 G3.7 功能配角（把卡片做厚）

原版把功能配角设计做厚，直接增强 G3.7：

### 1. 人设反差六维度法（给功能配角贴标签）

| 反差对 | 示例 |
|---|---|
| 表面 vs 内在性格 | 笑面虎 / 刀子嘴豆腐心 |
| 外表 vs 表面性格 | 看着凶实际软 |
| 外表 vs 内在性格 | 看着柔实际狠 |
| 身份 vs 生活方式 | 豪门子弟住地下室 |
| 身份 vs 爱好特长 | 杀手擅长插花 |
| 身份 vs 内在性格 | 军人内心文艺 |

从六维度选 1-2 个给配角贴标签；控制光环不超主角；功能配角不要强行立体化。

### 2. 配角功能化核心原则

- 配角能力特质必须和剧情紧密相关
- 配角为了展现主角而写——能力为主角所用，脱离困境靠主角帮助

### 3. 用配角做期待枢纽（人物扣）

- 选一个配角做「任务基地」，承载多个短期+长期期待
- 主角每次装逼后找该人物，开始新一轮
- 人物下线时用「歪打误撞收获更多」转变损失厌恶

## 七、注入于 G3.9 全人物核查（商业维健康度）

> 与原版两份「质量检查清单」对齐，作为 G3.9 交叉核查的**独立一栏「商业维健康度」**。

### 主角健康度
- [ ] 动机情感驱动（非「成为最强」空话）
- [ ] 有致命弱点，会在关键情节犯错
- [ ] 外貌有记忆点（3-5 关键词）
- [ ] 有口头禅/标志动作
- [ ] 逼格在线，未触碰红线（圣母/无脑战斗/内核邪恶/因蠢犯错/自暴自弃）
- [ ] 三层标签反差已设且内核反转
- [ ] 强关联 ≥3、动机链 CICR 齐备
- [ ] 代入感情感链条连续，无大段设定说明打断

### 配角健康度
- [ ] 有明确功能（导师/盟友/情报源/牺牲品/镜像对照）
- [ ] 核心特质 1-2 个关键词可概括
- [ ] 有标志性特征
- [ ] 退场方式已规划
- [ ] 同场景 ≤3 个配角有台词

### 反派健康度
- [ ] 反派四档层级已标注，篇幅与档位匹配
- [ ] 出场展示了实力/手段
- [ ] 动机从反派视角说得通
- [ ] 中等及以上至少赢主角一次
- [ ] 没有降智送赢
- [ ] 大弧 Boss 有理念冲突（不只利益）
- [ ] 最终 Boss 从第一章就有伏笔

### 商业红线（全程）
- [ ] 无「靠山过度」（紧张题材主角无强力靠山）
- [ ] 主角调子没起太高（或已压势化解）
- [ ] 代入感无断裂点（无现实逻辑评判触发）

## 八、与 G3 互补关系声明（防止替代）

| 维度 | G3 系列（源 B） | 原版方法（源 A，本表） | 关系 |
|---|---|---|---|
| 骨架 | 十步门链 / 层层确认 / JSON 可追溯 / 受阻恢复 | 无（方法散点，无门链） | 骨架取 B |
| 设计内容 | 由内而外（心结→弧线→外在）、与主题咬合 | 读者爽点/反差/记忆点/功能/代入感/反派四档 | 内容并集，A 注入 B 每步 |
| 质量闸 | 十项一致性自检 / 独特性红线 / G3.9 六项核查 | 原版 20+ 项商业健康度清单 | B 主、A 增补商业维 |
| 反派 | 只设「最重要反派」（1 人） | 反派四档层级表（规模分层） | A 补 B 缺口 |

> 结论：本表方法**只注入、不替代** G3 任何一步；G3 仍是主流程，本表是各步的「设计内容增强 + 商业维健康度清单」。
