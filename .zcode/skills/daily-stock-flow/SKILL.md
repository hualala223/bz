# daily-stock-flow：A股每日盘前/盘后全自动分析

把本地数据管道（bridge.py / run_ten_day.py / 盘面数据.py）串成一条**全自动**流水线，并按用户模板出报告。协议细节见工作区 `每日流程.md`（单一事实源）；分析框架见 `提示词1.md`（深度研究十三项）、`提示词2.md`（开盘定调/路径演化/操作矩阵）、`股票盘前分析.md` / `股票盘后分析.md`（模板）。本技能只做编排，不重复协议内容。

## 固定路径（本机）

- WORKSPACE = `N:\新建文件夹\股票分析`
- PY = `N:\新建文件夹\.venv\Scripts\python.exe`（venv，勿用系统 python）
- 报告目录 = `N:\新建文件夹\股票分析\股票分析-十日\个股报告\股票分析\股票\`
- detail JSON = `N:\新建文件夹\股票分析\股票分析-十日\个股报告\details\{代码}_{名称}.json`
- 行情快照/分时 = WORKSPACE\`行情数据\` 下 `{代码}_{YYYYMMDD}_行情快照.json` 与 `{代码}_{YYYYMMDD}_分时.csv`
- 默认标的 = WORKSPACE\`默认标的.txt`（未设时 300274；用户每次指定代码分析后更新该文件；说「全部」才分析 11 只）

## 执行前锚定（第 0 步，所有流程通用，任何平台不得跳过）

1. 校验 WORKSPACE（`N:\新建文件夹\股票分析`）存在，并把工作目录锚定到 WORKSPACE 再开始操作；后续读写一律用 WORKSPACE 绝对路径。
2. **先读工作区三件套再动手**：工作区 `AGENTS.md`（硬性纪律）→ `每日流程.md`（协议单一事实源）→ 本次对应模板（`股票盘前分析.md` / `股票盘后分析.md`）。本 SKILL 只做编排、不重复协议正文；跳过这些文件直接作答 = 流程不完整，属返工项。
3. 校验 PY（`N:\新建文件夹\.venv\Scripts\python.exe`）存在且可执行；缺失时明确报告并停止，**不得静默退回系统 python**。
4. 任一文件/路径缺失 → 列出缺失清单并停止，禁止凭记忆脑补流程。

## 平台差异说明

- **定时队列**：`schedule_*` 工具与 `[SCHEDULE REMINDER]` 仅 DSH 桌面端存在；无该工具的平台（如 ZCode）跳过「定时触发」一节的队列维护即可，不影响单次流程质量。ZCode 用户需要定时时，用其自带定时能力在用户显式要求下另行配置。
- **联网搜索**：无内置联网或搜索源受限的平台，严格按「数据口径纪律」执行——搜到的标注日期与来源；搜不到写「待核实」；全部失败明确写「联网失败，以下字段待人工核实」，严禁编造。
- **工作区上下文**：DSH 在本工作区打开时自动加载工作区 `AGENTS.md`；其他平台必须由第 0 步第 2 条显式读取，二者等效，缺一不可。

## 盘前流程（用户说「生成今日盘前分析」时依次执行）

1. **更新数据**：`run_daily.bat [代码]`（内部按序跑 bridge.py → run_ten_day.py → 盘面数据.py，日志写 `每日运行日志.txt`）。未指定代码时按**默认标的**（`默认标的.txt`）单只；说「全部」才全量 11 只。
2. **补当日快照**（仅当最新交易日 `行情快照.json`/`分时.csv` 缺失时）：运行 `pwsh -File "C:\Users\Administrator\.dsh\skills\intraday-analysis\scripts\fetch_intraday.ps1" -Code {代码} -OutDir 行情数据`；非交易日返回最近交易日并注明。
3. **读数据**：从 detail JSON 提取 stock_info/技术指标/K 线形态（9/2 起的近 30 行），从快照取当日量价，确认数据日期=最新交易日收盘；**再读上一交易日全天分时**（`行情数据\` 最新 `{代码}_分时_{上日}.csv`）做三项校验：①昨日尾盘 30 分钟拉尾/跳水 → 今日开盘定调；②昨日日内高低点 → 今日支撑/压力参考；③昨日分时量价与日线信号的印证（收阳高开低走=打折、收阴尾盘翻红=衰竭）。
4. **大盘盘面**：读 `盘面数据.py` 输出（指数/涨跌家数/成交额/资金净流入）。
5. **联网搜索**（注明日期与来源）：隔夜外盘（美东收盘实取：新浪 hq.sinajs.cn 的 gb_dji/ixic/inx + fx_susdcnh）、机构目标价、近 3 个月行业政策、近 1 个月个股公告（巨潮/新浪披露列表）、板块热度。
6. **生成报告**：按 `股票盘前分析.md` 模板 + `提示词1.md`（十三项深度研究）+ `提示词2.md`（外部环境/开盘定调/五路径概率/组合决策矩阵/硬止损/风险排序）撰写，存 `{名称}盘前分析{YYYY-MM-DD}.md`（同日覆盖）。
7. **人话总结**：对话里给结论——开盘定调、多空分界线、操作纪律（持仓/空仓两分支）、核心风险（概率×幅度）。

**完成标准**：报告文件存在且含模板全部章节（含"数据口径与免责声明"），并在对话给出可执行的盯盘结论。

## 盘后流程（「生成今日盘后分析」时）

同上 1-5 → **先取全天完整分时**：重跑 `fetch_intraday.ps1 -Code {代码} -OutDir 行情数据` 覆盖当日 CSV，另读 bridge 收盘后产出的 `stock_tools/data/{代码}分时.xls`，校验末笔=15:00 且根数 ≥230（不足重试，仍不足在报告标注"分时不完整+缺段"）→ 按 `股票盘后分析.md` 模板写当日走势复盘（分时段量价：竞价/早盘/午盘/午后/尾盘）+ 明日预测（压力/支撑/多空分界/情景概率）→ 存 `{名称}盘后分析{YYYY-MM-DD}.md` → 对话给人话复盘结论。

## 盘中流程（「盘中分析」口令或定时提醒触发）

加载 `intraday-analysis` 技能，按其规范执行：`fetch_intraday.ps1 -Code {代码} -OutDir 行情数据` 拉实时分时（东财→腾讯降级）→ 分时四段扫描（开盘30分钟/早盘/午盘/尾盘）→ 均价线与量价配合 → 关键支撑压力 → **未来盘中情景推演** → 风险提示。结论落盘 `{名称}盘中分析{YYYY-MM-DD}-{HHmm}.md`（同日多时段并存），并对话给盯盘结论。缺省按**默认标的**（`默认标的.txt`），说「全部」才跑 11 只。**盘中（9:30–15:00）禁止 bridge 全量刷新。**

## 定时触发（dsh-schedule，桌面端已开启）

收到含 `[SCHEDULE REMINDER]` 的消息且提示词为「生成今日盘前分析 / 生成今日盘后分析 / 盘中分析」时，**直接执行对应流程**（无需触发词）。
每次执行后维护提醒队列：用 `schedule_create`（`at: {date, time, time_zone: "Asia/Shanghai"}`，**08:30 盘前 + 10:00/11:00/13:30/14:30 盘中×4 + 18:30 盘后**）保证未来 5 个交易日每天 6 条；`schedule_list` 复核、`schedule_delete` 清理过期/多余项。盘后提醒定在 **18:30**（收盘数据全部落定后再出全天复盘，见用户 2026-09-07 要求）。非交易日/行情无更新：仅输出「今日非交易日，未生成报告」，不空跑数据链。

## 数据口径纪律（违反即返工）

- 行情不复权，与通达信导出一致；日线成交量单位=股，分时 CSV 成交量单位=手。
- 大盘资金净流入：优先东财原接口 → 降级同花顺全市场个股净额合计（**必须标注口径**）→ 两者不可用时**留空，不得编造或换语义**。
- 联网信息必须标注日期与来源；无法确认写"待核实"；报告尾附「信息来源清单」（检索时间/引擎/URL）；搜索全部失败须写明"联网失败，以下字段待人工核实"，不得跳过或编造。
- 量化评分/信号可用 `stockaskill` 技能（`diagnose`/`deep-diagnose`）交叉验证，程序输出仅供参考。
- 报告尾部固定附"本报告仅供参考，不构成投资建议"。

## 不要做

- 不要替用户启动 GUI 程序（`启动智能分析.bat`、`启动持仓管理.bat`、`分析股票.bat` 双击场景）——需人工操作的部分留给用户。
- 盘中（9:30–15:00）不要跑 `bridge.py` 全量刷新（会把当日未完成 K 线写进日线序列）；盘前/收盘后再跑。盘中数据需求走 `intraday-analysis` 技能。
