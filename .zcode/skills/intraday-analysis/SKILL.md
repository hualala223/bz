# intraday-analysis：A股盘中分时分析

对单只 A 股当天分时走势做量价分析，并对未来盘中走势做情景推演。数据优先自动拉取，用户提供时用用户数据。

**输入**：股票代码（`600519` / `sh600519` / `sz000001` / `1.600519` 均可），或用户直接提供的分时数据（粘贴文本 / CSV / 表格导出）。

**输出**：结构化盘中分析报告——数据快照 → 走势扫描 → 量价解读 → 关键位 → 未来盘中情景推演 → 风险提示。

## 工作流程

### Step 1 定标的与看盘背景
- 确认股票代码与名称；未提供代码时先问用户。
- 确认当前是否盘中（A股交易时段 9:30–11:30、13:00–15:00）。非交易时段按**复盘模式**处理：分析当日完整走势，推演窗口改为"下一交易时段/次日"。

### Step 2 获取当日分时数据
- **用户已提供数据**：校验字段（时间、价格、均价或可推算、成交量/额）；无均价则说明局限，用可计算的量价替代，直接进入 Step 3。
- **否则自动拉取**：运行
  `pwsh -File "C:\Users\Administrator\.dsh\skills\intraday-analysis\scripts\fetch_intraday.ps1" -Code 600519`
  需要 5 日分时做多日参考时加 `-Days 5`（仅东方财富数据源支持多日；腾讯备用源为单日）。脚本在当前工作目录生成 `{代码}_分时_{日期}.csv`（时间,开盘,现价,最高,最低,成交量手,成交额元,均价；量为每分钟增量、均价为累计 VWAP）与 `{代码}_行情快照_{日期}.json`。数据源双通道：东方财富优先、腾讯自动降级；非交易日自动返回最近交易日数据并在提示中说明。
- 完成标准：拿到当日全部分时点（收盘后完整 241 点，盘中为 09:30 至当前）；行情快照含昨收/今开/现价/最高/最低/成交量额。若拉取失败（脚本报 `NO_DATA` 或网络错误、非交易时段且用户无数据），**明确告知用户并请其提供数据，不得编造数据继续分析**。

### Step 3 数据预处理
- 读 CSV 确认逐行 = 一分钟；过滤 09:30 前的集合竞价行（仅作开盘价参考）。
- 计算：`涨跌幅 = (现价 − 昨收)/昨收`；`均价偏离率 = (现价 − 均价)/均价`；各时段成交量占全天比例。

### Step 4 分时结构扫描（分段法）
把当日切成四段，逐段记录方向、高低点、量能特征：
- **开盘 30 分钟（9:30–10:00）**：定全天基调。相对昨收的高开/低开/平开 × 头 30 分钟方向与量能 → 归类为高开高走 / 高开低走 / 低开高走 / 低开低走。
- **早盘（10:00–11:30）**：趋势延续或反转，重点看第二次冲击前高时的量能变化。
- **午盘（13:00–14:30）**：常为缩量整理，观察是否回踩均价线及其反应。
- **尾盘（14:30–15:00）**：拉升/砸盘决定收盘位置，影响下一时段（或次日开盘）预期。
- 记录整日极值点（最高/最低出现的时间与量能），把全天形态归类：单边推进 / 箱体震荡 / 冲高回落 / 探底回升。

### Step 5 量价与动能分析
- **均价线锚**：现价在均价上方 = 当日买盘主导，下方 = 卖压主导。均价偏离率 > 2–3% 属短线过热/超卖，有回归需求；均价线是动态支撑/压力，回踩不破为强、破位为转弱信号。
- **量价配合**：
  - 放量上涨创新高 = 动能健康；**放量滞涨**（量增价不涨）＝ 高位换手/出货嫌疑
  - 缩量上涨 = 上攻乏力；缩量回踩 = 惜售洗盘
  - 放量下跌 = 恐慌或出货；缩量下跌 = 抛压衰竭
  - 关键位（前高/均价线/整数关）的放量真突破 vs 缩量假突破
- **速率**：连续 3+ 分钟同向推进的斜率（急拉/急砸），以及急动后的衰减（缩量滞涨 / 止跌企稳）。

### Step 6 关键价位识别
列出支撑/压力表：昨收、今开、当日最高、当日最低、均价线、整数关口；有多日分时或日线参考时，补充前 N 日密集成交区（筹码密集区）。

### Step 7 情景推演（未来盘中走势）
不预测点位，输出 **情景 + 触发条件 + 目标位 + 时间窗** 的组合：
- **基准情景**：延续当前结构的最可能路径（例如：站稳均价线 → 逐级挑战当日高点）。
- **上破情景**：放量突破 XX 关键位 → 目标参考（前高/整数关/量度升幅），时间窗为当日剩余时段或下一时段。
- **下破情景**：跌破 XX（如均价线/当日低点）→ 支撑下移至 XX。
- 每条给出触发条件（什么盘面信号确认切换情景）与盯盘纪律：触发条件出现才切换情景；破位不扛、假突破不追。

### Step 8 输出报告
在对话中输出完整报告；用户要求时落盘为 `{代码}_盘中分析_{日期}.md` 到当前工作目录。
报告末尾固定附风险提示：**以上为基于量价结构的概率推演，非确定性预测，不构成投资建议。**

## 分析框架备注
- 数据拉取脚本：本 skill 目录下 `scripts/fetch_intraday.ps1`（东方财富分时接口为主、腾讯行情与东财实时盘口为辅；字段定义与接口细节以脚本内注释为准，不在本文重复维护单一事实源）。
- 分时分析不是日内预测保证：任何情景都只是概率最高路径，以触发条件为准。
