# 人物言行锚定协议（写正文·人物言行符合人物设计）

> 本文件定义：写每一章正文前，如何把「人物设计」的产物捏成**本章每个人物的言行锚定卡**，使出场人物的台词、内心、认知、动作都锚定在人物设计上，不跳出人设、不千人一面。
> 消费于 `story-long-write` Phase 4 写前准备的「状态筛选」之后的「人物言行锚定」步骤。本协议只做「召回 + 锚定」，不取代人物设计（那归 `story-character-lab` / `story-style-spec`）。

---

## 一、目的与边界

- **目的**：正文里每个人物的**言行举止符合其人物设计**——他说什么话、怎么想、怎么误解、怎么行动、怎么反应，都有出处，不靠写手临场发挥。
- **边界**：锚定卡里只有「这个人会怎么说话/怎么想/怎么做」的约束，不含「本章该演什么剧情」——剧情由细纲决定，两者不混。人物弧线在细纲/卷纲标了本章该变时，言行按「本章弧线节点」演变，其余默认维持既有人设。

## 二、时机

Phase 4「写前准备 → 状态筛选」之后、「模块/题材/文风召回」之前（或与之并列），对本章**按细纲出场名单**逐人做一次锚定。

## 三、输入（按细纲出场名单逐个读）

| 读什么 | 取哪些字段 | 锚到哪 |
|---|---|---|
| `设定/角色/{名}.md` 的语言特征卡小节 | `sentence_pattern`（句式）`word_preference`（词汇偏好/禁区）`catchphrase`（口头禅）`special_markers`（标点语气）`pace_rhythm`（语速节奏）`silence_mode`（沉默模式）`love_language`（爱的语言）＋ 潜台词方式 / 压力下语言变化 / 弧线语言演变 | 语言锚 |
| `设定/角色/{名}.md` 的认知/信念字段 | `dominant_auto_thought`（主导自动思维）`dominant_cognitive_bias`（主导认知偏差）`core_belief`（核心信念）`core_belief_stage`（信念阶段）`knot`（心结）`core_fear`（核心恐惧） | 思维认知锚 |
| `设定/角色/{名}.md` 的行为字段 | `behavior_patterns.signature_actions`（标志动作）`language_communication_style.typical_patterns`（典型表达）记忆点（口头禅/标志动作/行为重复点）`motivation_cicr`（动机链）＋ 性格类型（九型/MBTI/本能亚型/恐惧原型等） | 行为锚 |
| `追踪/角色状态/{名}.md` | identity（身份）location（位置）goal（当前目标）state（身心状态）knowledge（已知信息）open_threads（未结事项） | 状态锚 |

> 只读「如果不知道会写错」的字段，不整卷誊抄人设。一篇人设只取与本章出场相关的可执行约束。

## 四、产出：本章人物言行锚定卡

对本章每个出场人物，输出一条（可并入「写前准备」的召回摘要，作为 narrative-writer 的输入硬约束）：

```markdown
#### 人物言行锚定 · {角色名}
- 语言：{句式 + 口头禅/称呼 + 一道词汇禁区；一句话「这人的话长什么样」}
- 思维/认知：{主导自动思维 + 认知偏差；「他会怎么想、会误解什么」}
- 行为：{标志动作 + 典型反应；「他临场会做什么」}
- 此刻状态：{身份/位置/目标/身心状态一句话；「此刻他带着什么状态说话做事」}
```

**硬约束**：这张卡进入 narrative-writer 的 prompt，本章该人物的台词、内心、认知描写、动作，**不得跳出这张卡**。发现细纲要求与人设冲突时（如要求一个不善言辞的人突然大段煽情），标「言行与设计冲突」回细纲/卷纲确认，不用临时改人设糊弄过去。

## 五、人物言行样本不足时的补足（按需，不进每章默认必读）

人设卡缺 `language_communication_style` / `behavior_patterns` 等可执行样本时，按该角色「性格类型」字段映射 `行为词典/` 对应词典补足**[言行样本]，不整本加载**：

| 缺的维度 | 补足来源（`行为词典/`） |
|---|---|
| 情绪→行为表达、情绪化场景言行 | 情绪词典、微表情词典 |
| 性格→行为倾向、人格类型言行 | 0.3 人格行为词典、凯尔西气质类型词典 |
| 认知偏差、对话沟通模式 | 沟通行为与认知偏差词典 |
| 恐惧/本能驱动的行为 | 恐惧原型人格词典、完整的27型本能亚型词典 |
| 负面关系话语 / 反派话语 | 有毒的话语、煤气灯效应、精神虐待（冷暴力） |

> 行为词典只做「言行样本检索」，不改变人物已定的人设（性格类型、红线、动机链）。人设已充分时**不查词典**，避免画蛇添足。`工具箱/`（关系模式）属于人物关系设计（character-lab G3.0 第七步），不在此处消费。

## 六、与既有机制的衔接

- **语言距离**（style-spec 七级距离）：人物言行锚定管「这话/这动作像不像这个人」，语言距离管「镜头离人物多近」，两者正交、互不替代。
- **场景卡层**（story-scene-card）：场景卡的「g5_2_context 继承 + 行为分解（认知/记忆/应对/动机/行为逻辑/领悟/关系变化）+ 肢体语言映射」是**镜头级**的人物言行落点；本协议是**章级**的锚定，先于场景卡生效，场景卡继承本章锚定。
- **行为一致性核对**：`story-scene-card` 十步校验第②条「行为一致性」（台词风格 vs `language_communication_style.typical_patterns`、动作 vs `behavior_patterns.signature_actions`）在下游兜底复核，发现跳脱回改正文。

## 七、守门

- 本章出场人物**必须逐个有锚定卡**（主角 + 本章出场的核心/重要/功能角色；纯背景路人可只写一句「背景，不开口」）。
- 缺 `设定/角色/{名}.md`：先回 `story-character-lab` 补该角色人设（或 `[待补充]` 标注），不得用「大概是这样的人」临场发挥。
- 缺语言特征卡（未跑 `story-style-spec`）：按四锚里的语言锚标「待补」，本章对话照旧写、但记一条「语言特征卡缺失」欠账，择期补跑 style-spec。
