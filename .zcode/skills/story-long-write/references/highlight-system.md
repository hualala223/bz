# 爽点体系：九种类型 + 蓄力-引爆-余韵三段式

> 本文件定义爽点的结构形状（多章蓄力链与引爆节奏），与 `plot-emotion-system.md` 的六种情绪型爽点（单点情绪承载，如装逼层级、情绪模块）**分工不同、可叠加**：本文件管「一个爽点如何在多章里蓄力、引爆、收余韵」的宏观形状；plot-emotion-system 管「单个爽点内部用哪种情绪引擎兑现」。两者都命中时叠加使用，不冲突。

---

## 一、九种爽点类型

| 类型 | 适用位置 | 情感效果 | 设计要点 |
|---|---|---|---|
| 打脸反转型 | 冲突章/对峙章 | 憋屈→扬眉吐气 | 先压够（蓄积落差），引爆需读者能预见输赢方向但低估筹码 |
| 逆袭升级型 | 升级节点/实力突破 | 爽快+成长满足 | 突破代价可见，升级带来的碾压幅度要超出读者预判一档 |
| 捡漏/收获型 | 探索/交易/副本 | 惊喜+占便宜快感 | 收获要有代价锚点（先付成本）才不显廉价 |
| 身份揭露型 | 装逼/打脸/重逢 | 震惊+折服 | 揭露顺序设计落差：读者比对手早知道→对主角登场反应更爽 |
| 复仇兑现型 | 前期埋仇、中后引爆 | 快意恩仇 | 复仇必须清偿读者见证过的具体伤害，才够爽 |
| 守护救赎型 | 危机/牺牲/团聚 | 感动+温暖 | 让被守护方对守护行动有可感反馈，别演独角戏 |
| 资源滚雪球型 | 前期布局、后期兑现 | 布局兑现+掌控感 | 先期每步布局都让读者看见「在攒」，引爆时一次兑现多步 |
| 赌局/博弈型 | 智斗/谈判/竞技 | 紧张→豁然开朗 | 筹码和规则前置清楚，赢要赢在读者可复盘的信息差上 |
| 情感余韵型 | 卷末/关系线落定 | 满足+回甘 | 不靠大场面，靠人物关系终于点破的瞬间与代价的回望 |

## 二、三段式：蓄力 → 引爆 → 余韵

### 蓄力（引爆前 1-8 章）

| 蓄力档位 | 时长 | 手法 |
|---|---|---|
| 短蓄力 | 引爆前 1-3 章 | 埋一个具体落差/误判，读者能短期盯住 |
| 中蓄力 | 引爆前 5-10 章 | 分 2-3 次递进加压，每次给读者「再等等会更爽」的预期 |
| 长蓄力 | 贯穿全卷/全书 | 关键伏笔 + 期待债，只在明确回报时一次性引爆（大爽点） |

蓄力期每章在卷纲「爽点蓄力链」登记 TP-XX 进度（蓄力目标/当前进度），供 stepwise 卷门展示与爽点-紧张值联动。

### 引爆（单一章内的峰值）

- **一瞬炸裂**：多用于打脸/身份揭露/赌局——短段落内完成「落锤」，信息与动作同时到位。
- **逐步展开**：多用于逆袭/资源滚雪球——炸裂后有连续 2-4 个展开小节，逐层递进碾压，把读者情绪顶满再收。

### 余韵（引爆后收尾）

- **时长**：余韵小爽点约 1/3 章内收掉；大爽点可延续到下一章开头，不拖到 3 章以上。
- **三操作**：①给足读者「消化爽感」的镜头（反应镜头/配角态度）；②留下后续账（爽点带来的新冲突/新期待，避免爽完就空）；③防止过度余韵（情绪顶点之后连续两章无新钩子会泄气）。

## 三、密度标准

| 爽点级别 | 出现频率/总量 | 说明 |
|---|---|---|
| 小爽点 | 每 5-10 章 1 个 | 打脸/小收获，维持阅读节奏 |
| 中爽点 | 每 20-30 章 1 个 | 逆袭/身份揭露，中等蓄力 |
| 大爽点 | 全书 3-5 个 | 长蓄力引爆，对应卷末/阶段高潮 |
| 全书唯一 | 1 个 | 最终高潮（TP-08），必须是全篇最大蓄力点 |

> 密度不机械套用：按题材、目标字数、对标节奏调整（见 workflow-setup「全书体量与阶段总览」比例只作默认参考）。

## 四、蓄力链预分配（TP-01~08）

| 蓄力链 ID | 典型类型 | 建议引爆位置 | 蓄力目标 |
|---|---|---|---|
| TP-01 | 打脸反转 | 开篇期首个冲突章 | 让读者认同主角、见识金手指兑现 |
| TP-02 | 逆袭升级 | 发展期首个升级节点 | 建立「付出有回报」的阅读信任 |
| TP-03 | 身份揭露 | 发展期 | 提升主角权威感/装逼层级 |
| TP-04 | 资源滚雪球 | 发展期-高潮期衔接 | 前期布局首次集中兑现 |
| TP-05 | 复仇兑现 | 高潮期前段 | 清偿中前期埋下的具体仇怨 |
| TP-06 | 赌局/博弈 | 高潮期 | 智斗碾压，强化主角代理权 |
| TP-07 | 守护救赎 | 高潮期 | 情感余韵 + 关系线落定 |
| TP-08 | 全书唯一大爽点 | 最终高潮 | 全篇蓄力总引爆，必须>此前一切 |

> TP-XX 编号从 01 起顺延，可跳级/追加；每章细纲「爽点五字段」与卷纲「爽点蓄力链」用同一编号对齐，双向可追溯。

---

## 五、爽点-紧张值联动

- 引爆章对应的紧张值阈值：minor ≥5 / medium ≥7 / major ≥9 / 高潮=10 且全篇唯一（TP-08）。
- 蓄力期紧张值递增：蓄力不足就引爆（紧张值未达阈值）→ 爽感透支、读者无预期；过度蓄力迟迟不引爆 → 读者疲惫。
- 引爆后紧张值回落后立刻埋下一个蓄力起点，避免章节间情绪断层。

## 六、全局审查（批末/卷末）

- 蓄力链是否各有明确蓄力目标且卷纲登记了进度？
- 是否有「蓄力未足就引爆」或「蓄力过度不引爆」的失衡点？
- 大爽点是否与卷末/阶段高潮错开（避免连续大爆导致麻木）？
- 与 `plot-emotion-system.md` 的情绪模块是否叠加得当（结构形状 + 单点情绪承载）？
- 细纲「爽点五字段」（角色/类型/级别/蓄力目标/蓄力进度）是否与卷纲 TP-XX 一致？
