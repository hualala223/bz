# 场景强化规格与素材库（关键场景专用）

> 来源：用户《小说设置提示词》第六组精华，适配 oh-story 目录约定。数值均为默认参考值，可在 `设定/文风.md` 中按书覆盖。
>
> **口径声明**：苦笑比（占比，如 30%）= 苦笑/自嘲/错位类幽默占全部笑点比例；苦笑转化层次（L1-L5）= 苦笑分型谱系（confirmation-gates OB-5），两者不混用。

## 一、六类场景字数下限（预算参考）

| 场景类型 | 预算下限 | 说明 |
|---|---|---|
| 过渡/衔接 | ≥300 字 | 只求干净，不硬凑 |
| 内心/日常/铺垫 | ≥400-500 字 | 须带至少 1 个可感知细节 |
| 信息揭示 | ≥500 字 | 新概念首次出现须在冲突中被"使用"而非被说明 |
| 关系交锋（对话为主） | ≥600 字 | 对话占比 >60% 时检查是否注水 |
| 动作/对抗 | ≥800 字 | 节拍链逐拍可演 |
| 转折点/爽点引爆/高潮对决 | ≥800 字 | 强制走完整模板+障碍三连发 |

校验：各场景预算合计应落在章目标 ±10%；单场景实际字数 <80% 预算时回补节拍，不注水。

## 二、肢体语言映射表（通用兜底版）

规则：**每个出场角色的情绪必须翻译成可见动作**，叙述里不留孤立抽象情绪词。本书专属映射表建在 `设定/文风.md`；缺失时用下表兜底并在场景卡标 `[通用]`：

| 情绪 | 可见动作簇（选 1-2，不堆砌） |
|---|---|
| 紧张 | 手指摩挲杯沿 / 反复确认口袋里的东西 / 吞咽次数变多 |
| 愤怒 | 把物品放得极轻极慢 / 笑出声但眼神不动 |
| 心虚 | 抢先解释半句又收住 / 给对方递东西的手停在半空 |
| 悲伤 | 把碗里的饭一粒粒拨整齐 / 走路突然很稳 |
| 欣喜 | 先骂一句再笑 / 拎着东西一路换手拎 |
| 恐惧 | 后背贴墙站 / 记住了屋里所有出口 |
| 犹豫 | 门开了一半又合上 / 已读消息隔了很久才回 |
| 决绝 | 把手机扣在桌上 / 当众解下随身多年的物件 |
| 亲近 | 记得对方不吃香菜并提前挑掉 / 用对方说过的话回敬对方 |
| 敌意 | 客气地用全称呼 / 让座的动作慢半拍 |
| 崩溃 | 声音很平地继续做完手头的事 |

## 三、对话亮点规则

- 对话场景必给 **≥3 条功能性台词要点**（推动局面 / 揭示性格 / 制造转变），不写寒暄。
- 高光台词优先级：**不可挽回的话**（说出即覆水难收）＞ **决定性沉默**（该回应处不回应）＞ 机锋反讽。
- 关系变化场景的台词要点必须呼应细纲里该关系事件的触发原因。
- 对话被打断/拖长用动作与短句承接，不用省略号堆砌。

## 四、五感激活

- 每个关键场景 ≥3 种感官各有 1 条具体锚点（写"焦油味"，不写"很难闻"）。
- 爽点引爆场景：3 种感官同时骤变（声音消失/慢镜头特写/触觉锚点）；蓄力阶段：让同 1 种感官反复出现形成条件反射。
- 高潮对决四件套检查：听觉消失 / 视觉慢镜 / 触觉锚点 / 余韵瞬间。

## 五、障碍递进（强对抗场）

连续三道障碍逐级升高：第一障挡手 → 第二障断退路 → 第三障**打在心结上**（主角的缺陷/恐惧）或**踩中反派胜利剧本的关键节点**。第三障做不到绑定就降级为普通两障，不硬造。

## 六、伏笔配给

- 本场景涉及伏笔时标注三类动作之一：埋设（新线）/ 强化（旧线加压）/ 回收（兑现）。
- 埋设须配一种伪装：顺带提过 / 借物带出 / 他人转述 / 情绪化误读 / 场景装饰 / 半截话 / 反向强调。
- 全书节奏参考配比：第一部埋设约 40-50%，中期强化为主，尾部回收集中；每条伏笔回收前至少强化过 1 次。

## 七、幽默密度速查

- 幽默密度随剧情推进递减：开篇期最多（20-30% 场景可带）、发展期减半、高潮期趋零（高潮章禁用纯搞笑）。
- 默认幽默色 = 苦笑/自嘲/错位，服务人物塑造；纯搞笑 ≤10% 且不得打断高压节拍。
- **幽默苦笑比幕次表**（默认值，可在 `设定/文风.md` 覆盖；仅幽默启用时应用）：

| 幕次 | 每章笑点数 | 苦笑比（占比） | 备注 |
|---|---|---|---|
| 第一幕 | 2-3 | 20%-30% | 开篇喜剧浓度最高 |
| 第二幕前期 | 1-2 | 30%-50% | 幽默收紧，苦笑占比上升 |
| 第二幕后期 | 0-1 | 50%-70% | 冲突加深，幽默转苦涩 |
| 第三幕 | 0-1 | ≥70% | **高潮对决禁用**（禁用场景另有：绝望低谷、创伤闪回） |

- 苦笑比（占比） = 苦笑/自嘲/错位类幽默占全部笑点比例；本表与「详细场景卡比例」「高张力场景密度」构成公式三件套，计算与确认流程见 SKILL.md「容量规划」。

## 八、张力增强六件套（第六组 G6.3，高张力场景专用）

对高张力场景（转折点/爽点引爆/高潮）逐个做六件套草案，经用户确认后填入场景卡：

1. **感官强化**：爽点/转折场景五感从 3 条提至 4-5 条；引爆场 3 感官「强度骤变」（见第四节）。
2. **障碍三连发**：①外部物理障碍 → ②人际信息障碍 → ③内心信念障碍（**必须触及主角心结 `knot.description`，或踩中反派胜利剧本 `villain_victory_scenario` 的关键节点**）。若为关系变化触发章，第②障碍须含关系层面直接冲击，第③障碍进一步放大。
3. **记忆闪回**：插入 ≤80 字短回忆，与当前困境呼应（触发点 + 闪回内容 + 关联说明）。
4. **悬念种子**：场景结尾留未解谜题/危险预兆（留给读者的疑问 + 暗示真相的细节 + 计划回收章）。
5. **鸿沟强化**：明确主角预期 vs 实际意外的落差（预期 / 意外 / 后果）。
6. **幽默张力叠加**（幽默启用且场景不在禁用列表）：建议插在第②障碍后；技巧选自嘲/夸张/反差/双关/冷面/荒诞/误解/重复/反预期/文字游戏；写明苦笑转化效果（读者笑完意识到什么）+ 幽默后张力如何更强（第③障碍的沉重）。

## 九、场景卡级一致性十步校验（第六组 G6.5，卷末收口）

按卷末必做（连续批量每 5 章抽查；用户要求随时做）。十步 + 严重性分级（critical/major/minor），结果转「待修订清单」逐项经用户确认后回改：

1. **出场一致性**：出场角色与细纲规划一致，无「该在却不在/不该在却在」。
2. **行为一致性**：specific_behavior / 台词风格与人物 `behavior_patterns.signature_actions`、`language_communication_style.typical_patterns` 一致。
3. **心路阶段匹配**：`emotion`/`realization` 与 `arc_stage_structure_map` 当前阶段特征一致（不符标 ⚠️）。
4. **幽默风格**：启用幽默时，苦笑比/禁用场景遵守幕次表。
5. **关系变化追踪**：多人场景的关系变化已在行为分解「关系变化」字段记录。
6. **出场章节验证**：汇总每个人物实际出场章 vs 细纲规划出场范围，比对一致性。
7. **关系变化矩阵兑现**：逐 change_id 核对触发章在场景卡中是否有对应场景事件支撑。
8. **场景卡继承性抽查**：G3 人设关键成果（背叛条件/胜利剧本）、G2 象征物阶段意义、金手指最终代价等在场景卡中是否场景化落实（缺则 critical/high）。
9. **G5.2 爽点执行度抽查**：payoff 场五感「强度骤变」+ 引爆关键台词；buildup 场「反复微细节」+ 欲言又止。执行度分 高/中/低。
10. **G5.2 关系变化执行度抽查**：trigger 场不可逆行动 + 潜台词触及裂痕根源；buildup 场认知偏差 + 暗示紧张。执行度分 高/中/低。

执行度为「低/中」且需强化时生成修订建议（关系触发章优先级 high）。
