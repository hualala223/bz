# story-scene-card：章节场景卡

## 流程定位

上游 = 细纲（`story-outline-detail`，产 `大纲/细纲_第NNN章.md`）；下游 = 正文写作（`story-long-write` Phase 4）。场景卡是细纲的**镜头层展开**：只细化，不越界。**全书位置**：阶段 5 大纲（场景门），见 `story-stepwise/references/book-roadmap.md`。

完整链条：idea/选题 → 开书（`story-openbook`）→ 人物（`story-character-lab`）→ 卷纲 → 粗纲（`story-outline`）→ 细纲（`story-outline-detail`）→ **场景卡（本 skill）** → 正文 → 去 AI 味 → 审查。

## 双源声明（本 skill 为唯一权威，改前先对照 merge-directive）

- **主体**＝源 A（雪花分层、五元素节拍链、容量三件套「详细场景卡比例 / 高张力场景密度 / 幽默苦笑比幕次」）；
- **字段体系与校验**＝第六组 G6.1→G6.5（`g5_2_context` 继承链、五感/肢体/行为分解/对话亮点/叙述分解、要素完整性校验表、G6.5 场景卡级一致性十步校验）；
- **补充场景职责**划给细纲层（`story-outline-detail`）——场景卡发现素材不足只回细纲，**不自造事件**。

## 守门

- 卡壳信号、八维启发、3 轮占位、素材请求、（对话台词）素材请求、判断显式化 → 共享 `story-stepwise/references/interactive-protocol.md`。
- 目标章没有 `大纲/细纲_第NNN章.md` 时不做场景卡——先回 `story-outline-detail` 补细纲；细纲缺必需字段按补建规则先补齐。
- 场景卡**不引入**细纲没有的新主线事件、新具名角色、新反转；发现细纲撑不起本章时，输出「素材不足欠账点」并停止，回细纲流程补素材（**不自行造事件**）。欠账点因**新具名人物**而起时，同样回细纲——由细纲步骤 8 触发「人物增量补人流程」（`story-character-lab` 按层级深度设计），**场景卡层不得自行给新人物写速记人设**；补人完成后本 skill 对该章**重跑**：场景卡尚未落盘则从头走本章流程，已落盘则按「修订联动」只重做受影响场景。
- 场景卡不直接读粗纲——它通过细纲继承粗纲定下的情绪方向与结构约束。

## 流程

### 0. 读约束与输入

读 `大纲/_约束清单.md`（A 类硬约束为底线）、本章细纲全文 + 对应卷纲剧情单元 + `追踪/上下文.md` 出场角色当前状态。**完成标准**：能一句话说出本章目标情绪、必须兑现情节点、章尾钩子。

### 1. 容量规划（公式三件套，切场景前必做）

三件套为默认值，可在 `设定/文风.md` 按书覆盖；本卷已确认过则沿用：
- **详细场景卡比例** `r = min(1.0, max(0.2, 20/C + 0.1))`（C=全书计划章数）。
- **高张力场景密度** `d = max(1, floor(C/30))`。
- **幽默苦笑比幕次表**（仅幽默启用）：见 `references/scene-enhancement.md` 七。

以表格展示并说明依据，用户可改 C/幽默开关/参数；确认后记入本章场景卡头部「全局配置」注记。

### 2. 细纲可支撑性回查（第六组 G6.1 第一步，轻量）

切场景前核对：本章细纲的事件素材数（情节点序列 + α点三要素展开 + 补充事件）是否 ≥ 计划场景数。**不足时输出「素材不足欠账点」回 `story-outline-detail` 补，不硬拆、不自造事件**。校验表：

| 章节 | 计划场景数 | 可用素材数 | 是否充足 | 缺口处理 |
|---|---|---|---|---|
| N | （2-5） | （细纲事件数） | ✅/❌ | 回细纲补 / 无 |

### 3. 切场景

把本章切成 2-5 个场景，每场景至少一次实质局面推进（对抗/反转/升级/代价/关键信息变化）；纯过渡并入相邻场景，不单独成场。≥5 场提示考虑拆章。

同时完成「四类型分配 + 详细/简化标记」（G6.1 第四步 / 第七步）：
- **类型**：每章 ≥1 对话戏；动作戏 ≤1（转折点章必含 1）；内心戏 ≤1；过渡/氛围 ≤1。
- **详细/简化**：① 转折点章全部场景详细；② 主角首登场/心路转换章核心场景详细；③ 其余按 r 均匀分配，兜底每章 ≥1 详细。

### 4. 场景切分确认门

向用户展示切分方案（每场景一行「S{序号}：{一句话}（情绪：{词}）」），等确认/调整。确认前不填卡落盘。

### 5. 填卡（第六组 G6.2 字段体系 + 源 A 节拍链）

按确认方案逐场景填，写 `大纲/场景卡_第NNN章.md`。**关键场景**（转折点/爽点引爆/高潮/关系剧变）走完整模板（下节）；过场场景走简化字段（地点/出场/目标/节拍链/出口变化/字数）。

**填卡时逐场景做三类约束继承与联动**：

#### 5a. g5_2_context 继承（第六组 G6.1/G6.2 核心）

每场景头部显式列出继承自细纲的四项约束（markdown 注明，不引入 JSON）：
- **α点分解**：goal / obstacle / cost / emotion_arc（情绪弧 起点→转折→终点）——场景内微调不得偏离本章整体情绪方向。
- **爽点设计**：position（payoff/buildup/aftermath/none）+ 级别 + 蓄力目标 TP-XX。
- **关系事件**：role（trigger/buildup/none）+ 变化 ID/类型。
- **副线**：role（推进/爆发/收束/none）+ 副线 id `SP-XX`——仅当该场景承载某条副线的推进时填，其余标 none。

**细纲「逐章审查字段」五项的接力口径**（承上启下，避免悬空）：
- `humor_check`（幽默密度）→ 场景卡网格级遵守（见 scene-enhancement 幽默速查）；
- `stance_check`（角色不直说作者观点）、`transcendence_check`（禁止伪深刻/虚伪和解）→ **场景卡层兑现**（本场景台词/行为不得直说作者观点、高潮不得伪深刻）；
- `worse_off`、`stakes_tags` → 留在细纲层（章节属性），本场景卡不逐场景填，仅在故事情节需要时于出口状态变化体现 worse_off 结果。

#### 5b. 场景-爽点角色联动（第六组 G6.2 爽点联动规则）

- **引爆场（payoff）**：五感 ≥3 通道「强度骤变」（声音骤失/色彩刺目/触觉瞬冷）；对话含引爆瞬间关键台词（绑定 α点核心行动）；hook 体现象感余韵。
- **蓄力场（buildup）**：≥1 感官通道「反复出现」的微细节，与引爆场核心感官相呼应；至少一人物 goal 处于「被持续压制」。
- **余韵场（aftermath）**：hook 为下一爽点预埋蓄力钩子。

#### 5c. 场景-关系变化角色联动（第六组 G6.2 关系联动规则）

- **触发章（trigger）**：主导变化人物须记录「不可逆行动」，其 behavior_logic 引用深层信念/心结；对话含 ≥1 句「不可挽回的话」或「决定性沉默」；≥2 相关人物肢体语言体现「关系瞬间转变」（含 1 个犹豫瞬间特写）。
- **铺垫章（buildup）**：≥1 人肢体语言体现「与平时不同的微小异常」；对话用答非所问/过度礼貌/突然沉默/回避话题暗示紧张；≥1 人 cognition 体现「选择性忽略/过度解读」认知偏差。

### 6. 要素完整性校验（第六组 G6.2 内部执行）

逐场景按类型校验，不足自动补并在卡中标注「【自动补全】」：

| 场景类型 | 最低要素标准 |
|---|---|
| 对话戏（详细） | ≥6 对话轮次；≥3 肢体设计；五感 ≥3 项非空 |
| 动作戏（详细） | ≥5 动作节拍；≥3 感官细节；≥1 冲突升级点（处境更糟）|
| 内心戏（详细） | ≥1 记忆闪回/独白；≥3 身体反应；≥1 领悟点 |
| 过渡/氛围戏 | ≥2 感官细节；≥1 意象（象征性道具/描写）|

**爽点/关系附带校验**：引爆场五感 ≥3 通道骤变 + ≥1 引爆关键台词；蓄力场 ≥1 感官反复微细节；关系触发场不可逆行动 + 不可挽回的话 + 瞬间转变特写。**字数校验**：低于类型下限 80% 自动扩充并标注。

### 7. 自检与交付

① 各场景「出口状态变化」串联覆盖细纲「状态变化」；② 爽点/打脸/揭露场景能指到前置铺垫位；③ 末场景钩子与细纲结尾一致；④ 对话场景 ≥3 条亮点；⑤ 字数预算合计 ∈ 章目标 ±10%（**纯字口径＝汉字数不含标点**，见 long-write「字数验收权威」；场景数 2-5 不因纯字口径上调，2000 纯字章 3-4 场足够，素材不足回细纲补拍而非加场）。任一不满足回步骤 3 调整。

### 8. 跨章核查与卷末汇总（第六组 G6.5 十步校验，场景卡级收口）

单章落盘之外的卷级收口（逐卷末必做；连续批量每 5 章抽查 1 次）。十步校验落 `references/scene-enhancement.md`「场景卡级一致性十步校验」，此处列条目：

① 出场一致性 ② 行为一致性 ③ 心路阶段匹配 ④ 幽默风格 ⑤ 关系变化追踪 ⑥ 出场章节验证 ⑦ 关系变化矩阵兑现 ⑧ 场景卡继承性抽查（G3 人设/G2 象征/世界观关键时刻是否场景化落实）⑨ G5.2 爽点执行度抽查 ⑩ G5.2 关系变化执行度抽查。

汇总输出 `大纲/场景卡_第{V}卷汇总.md`：逐章场景概览、幽默幕次对照、伏笔埋-强-收统计、一致性核查结果与待修订项。核查发现问题先列清单（critical/major/minor），逐项经用户确认才改对应场景卡，沿用「未经确认不落盘」。

## 场景卡模板（关键场景完整版）

```markdown
# 场景卡 第{N}章 · {章名}
> 来源细纲：大纲/细纲_第{N}章.md ｜ 目标情绪：{情绪词} ｜ 全局配置：详细比例 {r} ｜ 高张力 {d} 章一遇 ｜ 幽默 {幕次段或停用}

## S1 {场景名}
- 场景类型 / 详细标记：{对话戏/动作戏/内心戏/过渡戏} · {详细/简化}
- g5_2_context 继承：α点 goal:{…} obstacle:{…} cost:{…} 情绪弧:{起点→终点}｜爽点 {position/级别/TP-XX}｜关系 {trigger/build-up/none·变化ID}｜副线 {推进/爆发/收束/none·SP-XX}
- 地点/时间：
- 出场：{角色 — 当下诉求/状态}
- 场景目标：推进细纲哪条情节点 + 交付什么情绪
- 目标→阻碍→代价：{想要什么 / 什么挡住 / 得不到会失去什么}
- 冲突：谁想要什么，为什么此刻得不到
- 节拍链：
  <环境> [动机]（动作）"话语" → 结果
- 五感锚点（爽点引爆场≥3感官骤变；蓄力场≥1感官反复）：视/听/嗅/触
- 肢体语言（每角色：情绪→可见动作，禁止孤立抽象情绪词）
- 对话亮点（对话戏≥3句功能性台词；关系触发场含"不可挽回的话"/"决定性沉默"）
- 障碍递进（动作戏强对抗场三连发，第三障绑定心结/反派胜利剧本）
- 行为分解（详细场景：认知/记忆/应对/动机/行为逻辑/领悟/关系变化）
- 悬念 / 钩子（钩子继承情绪弧终点；余韵场为下一爽点预埋）
- 伏笔：埋设/强化/回收 + 伪装方式
- 出口状态变化：{信息/关系/处境/能力可见变化}
- 字数预算：{X} 字
- 【自动补全】标注（如有）

## 章尾钩子：{与细纲结尾设定一致的下一章入口}
```

**节拍链五元素**：环境 `<>`、动机 `[]`、动作 `（）`、话语 `""`、结果 `→`（每条必选；其余按需）。每条链只写一个角色一次有效行动，多角色拆多条。

## 与写作衔接

- 写正文「按场景卡写第N章」：`story-long-write` 以场景卡为镜头顺序与节拍依据；**细纲优先边界不变**——场景卡与细纲冲突以细纲为准，提示是否修订场景卡。
- **修订联动**：细纲改动后该章场景卡视为过期，重跑本 skill；局部改动只重做受影响场景。细纲步骤 8 增量补人/改人完成后的回补同样适用本条——该章场景卡重跑，未落盘从头走、已落盘只重做受影响场景。
