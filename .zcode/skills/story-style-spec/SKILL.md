# story-style-spec：风格规格

## 定位

oh-story 写每章前都会读 `设定/文风.md`，且其内容**优先级高于对标文风**——本 skill 往这个最高优先级插槽里写你的风格规格。一本书跑一次即可；改风格 = 重跑本 skill。**与开书衔接**：story-openbook 的 OB-3.5 已在开书阶段锚定简化文风（核心风格关键词/文风锚点语/句长标点基调），本 skill 在已锚定简化版之上精化或重设，二者并存、非替换。前置：题材与基调已定（选题门通过即可），无需等大纲——此为可执行校验项，run 前按步骤 0 逐项检查并输出确认清单。

## 流程（每步展示要点等确认；逐步确认模式默认叠加，用户明示「快速模式」才解除。缺数据的自动补全遵循 A/B/C 模式：A 手动＝补齐后才能继续；B 智能自动＝可授权用兜底默认临时填充并标注【默认模板】；C 全自动＝自动填充、输出摘要后继续。未声明时按 B 模式执行。卡壳信号/八维启发轮换/3 轮终止占位的通用规则见 `story-stepwise/references/interactive-protocol.md`）

0. **前置校验与确认清单**（run 前必做，对应提示词 G7.0）
   - 校验三项输入，缺失项列出清单、不猜测：
     - `设定/题材定位.md`：题材 / 基调 / 主对标是否齐全且非空；
     - `追踪/上下文.md`：当前进度（已写卷/章、续写状态）是否可读；
     - `设定/角色/`：核心人物档案是否存在（至少主角＋主要配角每人有档，含性格关键词）。
   - 篇幅取值以 `设定/_开书.json` 的 `length_params` 为准（total_chapters / words_per_chapter / total_words / volume_tier）；缺失时按 AGENTS.md 篇幅字段权威**向用户索要**，禁止臆造默认值代入。
   - 缺失处理按 B 模式：先展示缺失报告草案；用户授权后用默认模板临时填充——总章节数=30、总卷数=1、每章 3000 字（仅作为【默认模板】占位，标注待后续替换，不代入篇幅公式）；默认主角模板（姓名「主角」，性格「谨慎内向」）；在产物中标注【默认模板】待后续替换；用户不授权则补齐后再继续。
   - 输出**项目状态确认清单**（等用户确认后才进入步骤 1）：

     | 维度 | 统计项 | 当前值 |
     | --- | --- | --- |
     | 篇幅 | 总章节数 / 总卷数 / 每章字数 | [读 `_开书.json` length_params，其次 `追踪/上下文.md`，再其次询问] |
     | 人物 | 核心人物数 / 姓名列表 | [读 设定/角色/ 档案清单] |
     | 风格基调 | 题材 / 基调 / 主对标 | [读 设定/题材定位.md] |

1. **风格定调**
   - 核心风格关键词 3-5 个（须附推导依据，禁止照抄示例词库）；
   - **风格锚点约束语**：50-100 字的一段话，原样写入文风文件，之后每章写作都受它约束；
   - 幽默配置三参数：默认类型（推荐苦笑/自嘲/错位）＋密度（随剧情推进递减，高潮章趋零）＋禁用场景清单。
2. **叙述视角与距离**
   - 视角人选：第一人称 / 第三单一 / 第三多线（多线须说清切换规则）；
   - 进入程度：浅层（摄影机）/ 电影 / 深层（可进内心），高压章贴内心、过场章拉远；
   - 不可靠叙述者只在有明确意图时启用，并注明读者何时该察觉；
   - **七级距离谱系（补充工具，不替代以上视角选择）**：最近-内心 / 近-感知 / 中近-行动 / 中-对话 / 中远-环境 / 远-旁观 / 最远-抽象——完整谱系、三类调节技术（拉近 / 推远 / 制造间离）、每场景距离策略卡与一致性检查表见 `references/language-distance.md`（对应提示词 G7.9）；
   - 逐场景距离规则（速记）：高压章贴内心（最近/近），过场章拉远（中/中远/远）；默认平稳过渡，突变仅限特殊场景并留最小过渡锚点，禁止远↔最近无过渡直跳；距离最终走向呼应主题升华。
3. **硬性语言规则**（量化段，写入文风文件）
   - 句长节奏：高张力段落均句长 ≤12 字、动词密度 ≥40%；舒缓段均句长 20-30 字；
   - 标点密度：破折号 ≤2 个/千字、感叹号 ≤3 个/千字、省略号只保留功能性用法（与去AI味脚本标准一致）；
   - 比喻：密度 ≤3-5 个/千字，明喻＜隐喻＜通感＜延展四级递进使用，生活化比喻优先；
   - **肢体语言强制**：抽象情绪词必须搭配可见动作（映射表用 `story-scene-card/references/scene-enhancement.md` 的通用表或本书自定义表）；
   - 五感：关键场景 ≥3 种感官各有具体锚点。
4. **开篇规范**
   - 三页清单：主角是谁 / 在哪 / 遇到什么麻烦——三页内必须全部落地；
   - 六大雷区自查：天气风景开场 / 梦境醒来 / 自我介绍式说明 / 大段设定倾倒 / 多线齐开 / 无事件慢热；
   - 读者三问终检：「那又怎样？」「噢是吗？」「呃？」——任何一问成立即改；
   - **钩子三型**（对应提示词 G7.5 2.1）：动作钩（进行中的具体动作）/ 意象钩（反常、有意味的画面）/ 哲学钩（颠覆常识的自白或判断）；写 50-100 字钩子段落并标注类型，必须落在前 200 字内；用户无想法时给出不同类型备选循环确认；
   - **炸弹埋设**（对应提示词 G7.5 2.2）：前 3 页（约 1000 字）内 ≥2 种——物理炸弹（倒计时 / 神秘包裹 / 遗留物件）/ 情感炸弹（异常婚戒 / 撕毁合影 / 未寄出的信）/ 哲学炸弹（颠覆常识自白）；在段落中标注位置（如 `[炸弹1：物理炸弹]`）；若 C>800 额外设计 1 个超长线炸弹；
   - **前 1000 字感官激活**（对应提示词 G7.5 2.4）：至少一种气味＋一种温度触感＋一种独特声音，标注位置（如 `[气味：……]`）；
   - 完整打磨段落输出 500-800 字，钩子 / 炸弹 / 感官 / 肢体语言用注释标注；检查未过则输出「已执行的开篇修正」表，3 轮迭代仍不过的项记入待人工处理。
5. **人物语言特征卡**（核心层每人一卡，写入该角色 `设定/角色/{名}.md` 的语言特征卡小节）
   - 基础十要素＝原七要素（句式习惯 / 词汇偏好与禁区 / 口头禅与标志性称呼 / 标点语气习惯 / 潜台词方式 / 压力下的语言变化 / 随弧线的语言演变）＋三个基础字段（对应提示词 G7.2 第二步）：**语速/节奏**（说话快慢与停顿习惯）、**沉默模式**（何种情境下沉默、时长与方式；默认参考：被质疑核心信念时沉默）、**爱的语言体现**（肯定言词 / 服务行动 / 接受礼物 / 精心时刻 / 身体接触五型；默认参考：服务的行动）。每字段须附推导依据，逐人确认；
   - **沟通行为扩展（可选）**（对应提示词 G7.2 第三步）：触发条件＝该角色档案已有 core_belief 或 auto_thought 字段，触发与否须显式报告。增补字段：dominant_auto_thought（主导自动思维：判断 / 指责 / 强迫 / 比较 / 理所当然 / 合理化 6 模式）、dominant_cognitive_bias（主导认知偏差：读心术 / 二分法思维 / 精神过滤 / 个人化 / 灾难化 / 妄自断定 6 偏差）、core_belief_stage（固着/松动/拉锯/决断/整合，静态标「恒定」）、language_evolution_marker（语言演变轨迹，如「判断句→观察句」）；模式映射表见提示词原文，可精简引用；
   - **字段映射（将来 JSON 化直接并入 `language_profile`）**：句式习惯→sentence_pattern，词汇偏好→word_preference，口头禅→catchphrase，标点语气→special_markers，语速/节奏→pace_rhythm，沉默模式→silence_mode，爱的语言体现→love_language，主导自动思维→dominant_auto_thought，认知偏差→dominant_cognitive_bias，信念阶段→core_belief_stage，演变标记→language_evolution_marker；潜台词方式、压力下的语言变化无直接键，并入 special_markers 或扩展字段；
   - 确认粒度：基础卡逐人确认；扩展卡按流程头 A/B/C 模式伸缩（B 模式默认逐人展示草案确认一次）。
6. **落盘生效**：汇总写入 `设定/文风.md`（分节：锚点语 / 视角与距离 / 量化规则 / 开篇规范 / 幽默配置），展示最终结构，经你确认后生效。

> 生效机制：此后每个日更回路的写前召回会自动读本文件作权威风格基；`story-deslop` 的清理标准与这里的量化规则同源一致。
