# 语言距离参考：七级距离谱系与调节技术

> 属 `story-style-spec` skill「叙述视角与距离」步骤的补充工具表，源自用户自有《小说设置提示词》G7.4（叙述视角选择与稳定性检查）与 G7.9（距离调节工具·情感强度控制）。SKILL.md 步骤 2 挂载本文件；正文写作与开篇打磨时可随时召回查表。

## 一、七级距离谱系

| 层级 | 名称 | 呈现方式 | 情感强度 | 示例句 |
| --- | --- | --- | --- | --- |
| 最近 | 内心 | 直接内心独白、意识流 | 极高 | 「他不能死。绝对不能。血还在流。」 |
| 近 | 感知 | 第三人称有限，紧贴角色感官 | 高 | 「他听见自己的心跳声，像鼓点砸在耳膜上。」 |
| 中近 | 行动 | 聚焦角色的动作和行为 | 中高 | 「他冲过去，按住伤口，血从指缝涌出。」 |
| 中 | 对话 | 主要通过对话呈现 | 中 | 「你还好吗？」「我……没事。」 |
| 中远 | 环境 | 聚焦环境，人物在其中 | 中低 | 「雨下得很大。地上有一摊血。」 |
| 远 | 旁观 | 叙述者冷眼旁观，不进入内心 | 低 | 「他受了伤。旁观者报了警。」 |
| 最远 | 抽象 | 哲思、总结、象征 | 极低 | 「伤与痛，不过是生命的常态。」 |

使用注意：

- 以上示例句仅为定义参考；落到本书场景时必须创作符合本项目情境的原创示例段落，严禁整句照搬。
- 谱系与视角的兼容前提：最近/近/中近 依赖「可进内心/紧贴感知」的视角（第一人称、第三有限、深层进入）；全知或纯旁观视角天然偏中远/远。设计前先与 SKILL.md 步骤 2 定下的视角人选对齐。

## 二、距离调节技术（三类）

| 想要的效果 | 技术手段 | 示例 |
| --- | --- | --- |
| 拉近距离 | 从「他感到」变为直接呈现感受；减少叙述者过滤；使用现在时；增加感官细节 | 原：「他感到很害怕」→ 改：「手在抖。汗在流。牙关在打颤。」 |
| 推远距离 | 增加叙述者评论；使用过去完成时；聚焦环境而非内心；增加时间跨度 | 原：「她心碎了」→ 改：「那之后的三个月，她再也没笑过。」 |
| 制造间离 | 突然切换到环境描写；插入象征性意象；改变句式节奏 | 「枪响了。窗外，一片叶子从树上落下。」 |

## 四、距离一致性检查（三项）

对全篇（基于场景卡规划）逐项检查，每项给出风险评估（高/中/低）与调整建议：

| 检查项 | 问题描述 |
| --- | --- |
| 距离跳跃过猛 | 从极远突然跳到极近、无过渡 |
| 该近却远 | 情感高潮处距离过远，削弱感染力 |
| 该远却近 | 过渡场景过度进入内心，节奏拖沓 |

- 执行要求：任一项风险为「高」或「中」，或与视角不兼容（见第一节兼容前提），必须强制修正——定位问题场景 → 直接修改/重生成该场景距离策略卡 → 输出「已执行的距离修正」表（无修正也输出并标注「无需修正」）；用户可确认应用或跳过。

## 五、可选扩展：距离与核心信念/自动思维的匹配

触发条件：核心人物存在 `core_belief_stage` 或 `auto_thought_intensity` 字段，且总章节数 C ≥ 80。不满足则跳过并标注「沟通行为距离扩展未触发」。确认粒度按 SKILL.md 流程头说明的 A/B/C 模式伸缩（B 模式默认逐表确认一次）。

- 核心信念阶段 → 推荐主导距离层级：

| 阶段 | 推荐层级 |
| --- | --- |
| 固着期 | 中近（行动）+ 中（对话） |
| 松动期 | 近（感知） |
| 拉锯期 | 最近（内心）+ 中近交替 |
| 决断期 | 最近（内心）+ 近（感知） |
| 整合期 | 中（对话）+ 中远（环境） |

- 自动思维强度 → 推荐调节技术：T1 无反思＝中近快速切换、少内心；T2 偶有停顿＝中近+偶尔拉近到感知；T3 新旧交替＝内心与行动频繁交替；T4 主动暂停＝最近+近；T5 健康习惯＝中（对话）自然流畅。
- 分卷映射（V>1 时）：将各卷映射到信念阶段与距离轨迹，如 第一卷/固着期：中近→中、稳定偶尔拉近；终卷/整合期：最近→中、逐渐推远回归平和。

## 六、主题关联与全局纪律

- 距离的最终变化应呼应主题升华（从主题金句提取）：收束段落可落最远（抽象）作总结，但最远层级全篇应克制出现，避免滥用哲思总结稀释现场感。
- 健康对话场景保持中层级（不贴内心也不旁观）。
